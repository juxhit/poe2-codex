# Glossary

> Community slang and mechanics shorthand. Detailed mechanics: [mechanics/](mechanics/index.md)

## General slang

| Term | Meaning |
|---|---|
| **AoE** | Area of Effect |
| **DoT** | Damage over Time |
| **DPS** | Damage per Second |
| **EHP** | Effective Health Pool (how much raw damage you survive after mitigations) |
| **More vs Increased** | "Increased/Reduced" = additive with same-stat sources; "More/Less" = multiplicative — see [mechanics/life-mana-es.md](mechanics/life-mana-es.md) |
| **CC** | Crowd Control (stun, freeze, pin…) |
| **Clear** | Monster-killing speed in maps |
| **Single target / ST** | Boss-focused damage |
| **QoL** | Quality of Life |
| **League starter** | Build picked to start a fresh economy league cheaply |
| **SSF** | Solo Self-Found (no trading) |
| **HC** | Hardcore (permanent death) |
| **RIP** | Hardcore character death |
| **Alt-tab / overlay** | Price-checking outside the game window |
| **RMT** | Real-Money Trading (bannable) |
| **Mirror-tier** | Item worth approaching Mirror of Kalandra value |
| **Crafting bench** | PoE1 term; PoE2 uses Reforging/Salvage benches + direct currency — see [crafting/](crafting/index.md) |

## Combat & stats

| Term | Meaning |
|---|---|
| **Ailment Threshold** | Hidden stat vs ailment application; players = half max Life — see [mechanics/ailments.md](mechanics/ailments.md) |
| **Ignite / Shock / Chill / Freeze** | Fire DoT (20% of hit) / +dmg taken / action slow / action lock |
| **Bleed / Poison** | Phys DoT (doubles on move) / Chaos DoT (one stack by default) — both bypass ES |
| **Electrocute** | Lightning action lock (build-up based) |
| **Heavy Stun** | 100% stun build-up bar → several seconds of inaction |
| **Pin / Immobilise** | Projectile-based / umbrella state (Heavy Stun, Pin, Freeze, Electrocute) |
| **Culling Strike** | Instant kill vs enemies below 10% Life |
| **Execute** | Damage vs Low Life |
| **Armour Break / Fully Broken** | Reduce armour (can go below 0 with Imploding Impacts) |
| **Exposure** | −Resistance debuff type |
| **Wither** | Stacking chaos-damage-taken debuff |
| **Onslaught** | +buff to attack/cast/move speed |
| **Tailwind** | Action speed buff (Deadeye) |
| **Leech** | Recovery over 1s scaled to hit; one instance per resource — see [mechanics/leech.md](mechanics/leech.md) |
| **Recoup** | Delayed recovery of a % of damage taken/dealt |
| **Lucky / Unlucky** | Roll twice take best / worst — see [mechanics/damage-types.md](mechanics/damage-types.md) |
| **Entropy** | Deterministic evasion system |
| **Presence** | Radius around you for aura-like effects |
| **Reservation** | Permanent commitment of Spirit (or Darkness/Infernal Flame systems) |

## Items & economy

| Term | Meaning |
|---|---|
| **T16 / T1** | Waystone tier (endgame difficulty, 1–16) |
| **Ilvl** | Item level (caps modifier tiers) |
| **Fractured** | Permanently locked modifier — see [crafting/fractured-desecration.md](crafting/fractured-desecration.md) |
| **Desecrated** | Exclusive Abyss modifier |
| **Forgemarked** | 1.0 league modifier selected for permanent fracture |
| **Magic find / IIR / IIQ** | Item Rarity / Quantity increases |
| **Wsd / Waystone drop chance** | Map sustain stat |
| **Pinnacle** | Endgame boss tier (Arbiter, Xesht, King in the Mists…) |
| **Barya / Ultimatum** | Trial keys (Sekhemas / Chaos) |
| **Splinter** | 1/300 stack fragment → boss key |
| **Base** | The underlying item type |
| **TTFK** | Time-Lost jewels shorthand `(community usage varies)` |

## Builds

| Term | Meaning |
|---|---|
| **CoC** | Cast on Critical (meta gem) — see [skills/meta-gems.md](skills/meta-gems.md) |
| **CoD / CoA / CoMD** | Cast on Dodge / Ailment / Minion Death |
| **Totem / Minion / Herald** | Persistent playstyles |
| **Triggerbots** | Bannable automation; do not confuse with meta gems |
| **PPT** | Weapon Set Passive Points |
| **Ascendancy** | Class subclass chosen via trials |
| **Uber** | Strongest boss version (Uber act bosses, Ubers = pinnacle variants) |
