# Game Modes — SSF, Hardcore, Co-op

> Death/hardcore base rules: [mechanics/death-trade-party.md](../mechanics/death-trade-party.md) · This file: practical mode guidance.

## SSF (Solo Self-Found)

- Opt-in checkbox at character creation; **no trading** — self-farm everything ([death rules](../mechanics/death-trade-party.md)).
- Crafting self-sufficiency: master the Reforging Bench 3→1 and essence crafting early — [crafting/](../crafting/index.md).
- Best solo farming: Ritual (uniques/omens), Expedition remnants (permanent boons), waystone sustain via unidentified-drop trick — [mechanics/league-mechanics.md](../mechanics/league-mechanics.md), [guides/endgame-progression.md](endgame-progression.md).
- Chase uniques come from targeted sources (Sekhemas relic drops, pinnacle keys) rather than trade — see [bosses/pinnacle-bosses.md](../bosses/pinnacle-bosses.md).

## ⚠️ Hardcore (HC)

- Permanent death → character + inventory **migrate to Standard**; HC stash stays in HC for your next character; PvP deaths also delete — see [death-trade-party.md](../mechanics/death-trade-party.md).

!!! danger "One-shot mechanics to respect `(community consensus)`"
    - Massive telegraphed slams at endgame tiers (Brambleghast's Volatile Slam analogs; Uber act-boss refracted beams — Doryani's Fist is lethal).
    - **Reflected damage** and Overcharge-style shock reflections ([skills/support-gems.md](../skills/support-gems.md)).
    - Sekhemas Honour builds: 0 Honour = run ends — stack Honour Resistance ([mechanics/trials.md](../mechanics/trials.md)).
    - Ritual Kings / Rite of the Nameless chains with escalating affixes.

- Recommended baseline before endgame HC: 75%+ res, ~3k+ EHP, ailment immunity charms ([mechanics/flasks-charms.md](../mechanics/flasks-charms.md)).

## Party / Co-op

| Rule | Detail |
|---|---|
| **Loot** | Shared visible drops; leader sets allocation (FFA default / Short ~5s window / Permanent) `(mode availability patch-dependent)` |
| **Drop bonus** | Total drops ~+28% per extra member; currency/gold up to +100% more `(unconfirmed exact)`; boss quantity = **minimum** of players at fight start AND end — leaving mid-fight reduces drops |
| **XP** | Shared, weighted to higher-level players; big gaps starve the low level; parties up to **6** |
| **Quest/Atlas progress** | **Only the party leader** gets quest credit and Atlas points — rotate leader per waystone |
| **Portals** | **One portal per waystone instance** (not 6): leaving mid-map can lock you out; party joins via portal icon by the leader's portrait |
| **Couch co-op** | PS5/Xbox shared-screen, cross-play + cross-progression; both players use the **same account**; two-account game-share not supported (as of 0.5.5) |
| **Monster scaling** | ~+50–60% more life per extra player `(unconfirmed)` — see [death-trade-party.md](../mechanics/death-trade-party.md) |
