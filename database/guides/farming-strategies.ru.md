# Стратегии фарма в эндгейме

> Тир-лист стратегий: [Maxroll endgame farming tier list](https://maxroll.gg/poe2/tierlists/endgame-farming-tier-list) (0.5.5). Механики: [mechanics/league-mechanics.md](../mechanics/league-mechanics.md) · Прогрессия: [endgame-progression.md](endgame-progression.md)

## Тиры стратегий (0.5.5, Maxroll)

| Тир | Стратегия | Почему |
|---|---|---|
| **S** | **200% Delirium + Abyss** | Liquid/Ancient Emotions + Gnawed Bones + рары = лучшая плотность валюты/XP |
| **S** | **Фарм планшетов (Tablet farming)** | Планшеты Precursor усиливают паки + целевые лиговые спавны; сочетайте с камнями на pack-size |
| **S** | **Ritual** | Tribute → **только Уники или Омены** в эндгейме; откладывайте дорогие предметы при 15% |
| **A** | Delirium Boss Rush (волны Simulacrum) | Ключ пиннакла + крафт эмоций |
| **A** | Фарм рарок на Breach | Крафт Genesis Tree, Hiveblood/Wombgifts |
| **A** | Охота за Citadel | Уники Uber-боссов актов + Crisis Fragments (доступ к Arbiter) |

## Пресеты по целям

### Валюта (чистые сферы)
- Атлас: ноды pack size + rarity; моды путевых камней: Rarity ≥10% + Pack Size; усиление зеркалами Delirium на 200%.
- Механики: Ritual (омены) + Abyss (кости для крафта Desecration) — продавайте результаты ([crafting/fractured-desecration.md](../crafting/fractured-desecration.md)).

### Уники и боссы
- Фармите **King in the Mists** (Rite of the Nameless) ради уников Ritual; **Sekhemas с реликвиями на уники** ради гарантированных дропов Zarokh ([mechanics/trials.md](../mechanics/trials.md)); **Citadels** ради уников Uber-боссов актов — см. [bosses/pinnacle-bosses.md](../bosses/pinnacle-bosses.md).
- Simulacrum 7 волн → ключ пиннакла Delirium.

### Золото (респек/азартная игра/жалование)
- Золото скейлится с количеством: **путевые камни T16 с magic-find + алтари (Seeking: +100% rarity)** + моды в стиле «of the Devoted»; золото падает со всех убийств — см. [vendors-hideout.md](vendors-hideout.md) о том, что на него покупается.

### XP до 100
- Карты Delirium 200%+ (самая высокая плотность монстров × множители XP); enlightening-алтари (+100% XP); избегайте штрафа смерти 10%, играя безопасные моды — смерть забирает 10% опыта текущего уровня с ~65 ур. ([mechanics/death-trade-party.md](../mechanics/death-trade-party.md)).

## Комбинации планшетов (Precursor Tablets, 3 гнезда на Map Device)

- **Стакинг одного типа усиливает** — например, два планшета Breach стакают частоту спавна Breach; добавьте планшет Abyss для плотности между механиками.
- Планшет «Unforeseen Consequences» + планшет на pack-size = стандартная база усиленного забега; «Energized Ley Lines» удваивает эффекты.
- Fracturing Orbs и некоторые крафты планшетов требуют специализации пассивок Атласа — [mechanics/atlas-waystones.md](../mechanics/atlas-waystones.md).

## Пресеты Атласа

- Отдельные деревья Атласа существуют для каждой лиговой механики (дерево Runes of Aldur добавлено в 0.5.4; Breach = Monastery of the Keepers; Ritual = Caer Tarth).
- Универсальный пресет на валюту: ноды шанса дропа путевых камней → pack size → rarity → ноды ваших 2 выбранных механик → ноды алтарей.
- Полные карты нод по каждой механике: `(нет данных)` — брать из разделов Атласа Maxroll при расширении.

## Быстрые правила выбора путевого камня

- Опознавайте **только ради трюка с шансом дропа**, когда с сустейном всё хорошо; иначе опознавайте и перекатывайте на Quantity/Rarity/Pack Size.
- Regex-фильтры для перекатов: [cheatsheets/regex.md](../cheatsheets/regex.md).
- 3 камня одного тира → 1 камень более высокого тира на Reforging Bench; боссы дропают +1 тир.
