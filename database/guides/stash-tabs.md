# Stash Tabs & Organization

> Sources: [Fextralife — Stash Tabs](https://pathofexile2.wiki.fextralife.com/Stash_Tabs), [GGG Map Stash Tab announcement](https://www.pathofexile.com/forum/view-thread/3723891), official 0.5.0 notes. **10 points = $1.** You start with 4 Basic tabs.

## Tab catalog

| Tab | Points | Notes |
|---|---|---|
| Basic Stash Tab | 30 | Cannot be public |
| **Premium Stash Tab** | 40 | **Public → trade-site listing**; upgrade Basic→Premium for 15 |
| **Quad (Premium) Tab** | 150 | 4× Premium space |
| **Currency Tab** | 75 | 5,000 of each currency + 1 central slot + 14 wildcard stackable slots |
| **Map / Waystone Tab** | 150 (sale 120) | Up to **576 waystones per tier**, 6 sub-tabs per tier, waystone affinity |
| Gem Tab | 40 | Up to 500 skill/support/spirit gems |
| Flask Tab | 40 | Up to 500 flasks |
| Delirium Tab | 40 | Distilled/Liquid Emotions, Simulacrum splinters, instilled maps |
| Essence Tab | 40 | All essences incl. Greater; gear slot + 4 wildcards |
| Unique Collection Tab | 140 | One copy of every unique (collector/SSF) |
| Fragment Stash Tab | 60 `(price unconfirmed)` | Fragments (Breach splinters, Audience keys), Inscribed Ultimatums, Baryas **and Tablets**; auto-granted to PoE1 Fragment-tab owners |
| Guild Stash Tabs | higher `(price not documented)` | Shared guild storage |

## Buying priority (community consensus, 0.5-era)

1. **Currency Tab** — the single biggest QoL/economy win.
2. **Waystone/Map Tab** — once you're mapping (huge sustain organization).
3. **2–4 Premium tabs** (public) — for trade listings.
4. Gem / Essence tabs → Quad → rest (Delirium/Fragment/Unique are niche).

## Stash Affinities

- Assign item classes to a tab: **Ctrl-click deposits auto-route** there (Currency, Gems, Waystones, Essences, Delirium, Flasks, Uniques…). Premium tabs can hold one affinity too.
- Features: **Tab Folders** (group tabs), affinity on/off toggle, **affinity auto-navigation** (jump to the tab on Ctrl-click), **Ctrl+Shift-click bypasses affinity**.
- Hideout "Other Stashes" objects have fixed affinities but aren't purchasable.
