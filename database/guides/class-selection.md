# Class Selection Guide

> Full class data: [classes/](../) · Ascendancies: [ascendancies/](../ascendancies/)

| Class | Attributes | Weapons | Feel | Beginner-friendly? |
|---|---|---|---|---|
| Warrior | Str | Maces (2h/1h+shield) | Slow slams, stuns, active block | Yes — tanky, forgiving |
| Witch | Int | Wands + focus | Minion army, chaos spells, curses | Yes — safe, passive-ish |
| Ranger | Dex | Bows | Fast projectiles, poisons, vaulting | Medium — squishy, mobile |
| Sorceress | Int | Staves/wands/foci | Elemental spells, trigger gems | Medium — glass cannon |
| Mercenary | Str/Dex | Crossbows + grenades | FPS-style ammo combos | Medium — unique feel |
| Monk | Dex/Int | Quarterstaves | Fast melee, combo finishers, bells | Hard — high execution |
| Huntress | Dex | Spears + buckler parry | Melee/throw hybrids, detonations | Hard — parry timing |
| Druid | Str/Int | Talismans (shapeshift) | Bear/Wolf/Wyvern + spells | Medium — new in 0.4.0 |

## Decision shortcuts

- Want **minions/pets**: Witch (or Druid forms; Spirit Walker bear companion is an ascendancy, not a class pick).
- Want **tanky melee**: Warrior (Titan/Warbringer) or Smith of Kitava for self-forged gear.
- Want **spellcasting**: Sorceress (Stormweaver = easiest), Witch (Lich/Blood Mage for riskier styles).
- Want **ranged DPS**: Ranger (Deadeye for projectiles, Pathfinder for poison/concoctions) or Mercenary (crossbow combos).
- Want **fast flashy melee**: Monk (Invoker for elemental) — high ceiling, low defence.
- Want **unusual mechanics**: Mercenary Gemling (attributes), Acolyte of Chayula (Darkness), Chronomancer (time), Oracle (foresight crits).

## Ascendancy pairing cheat-sheet (0.5.x)

- Warrior → Titan (slams) / Warbringer (totems+armour break) / Smith of Kitava (defence+fire)
- Monk → Invoker (elemental melee) / Acolyte of Chayula (chaos+Darkness) / Martial Artist (clones+bells)
- Sorceress → Stormweaver (shock/chill) / Chronomancer (time) / Disciple of Varashta (djinns)
- Mercenary → Witchhunter (bossing) / Gemling (attributes) / Tactician (banners/ballistas)
- Ranger → Deadeye (projectiles) / Pathfinder (poison/flasks)
- Witch → Infernalist (demon form) / Blood Mage (life-cost) / Lich (curses+ES)
- Huntress → Amazon (crit) / Ritualist (rings/charms) / Spirit Walker (spirits)
- Druid → Shaman (rage spells) / Oracle (crit/foresight)
