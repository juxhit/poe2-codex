# Гайд для новичков

## Создание персонажа

- Выбирайте класс по ощущениям, а не по страху — любой класс может использовать любой камень умений; идентичность = атрибуты + стартовая позиция на дереве + восхождения ([classes/](../classes/)).
- Гибриды (Monk, Mercenary, Druid) имеют гибкие деревья; чистые классы (Warrior, Ranger, Witch, Sorceress) более сфокусированы.
- Выбор мира: Softcore vs Hardcore vs SSF ([mechanics/death-trade-party.md](../mechanics/death-trade-party.md)).

## Первые часы

1. **Умения берутся из Uncut Skill Gems** — вы сами выбираете, какое умение выучить; ничего нельзя пропустить.
2. Камни поддержки вставляются **прямо в камни умений** (без связок) — количество гнёзд растёт через Jeweller's Orbs.
3. Добавляйте камни поддержки, соответствующие вашему типу урона; не распыляйтесь на разные типы в начале ([mechanics/damage-types.md](../mechanics/damage-types.md)).
4. **Сопротивления важны начиная с Акта 2** — кампания даёт −10% реза за акт ([mechanics/defences.md](../mechanics/defences.md)).
5. Кувырок (Space) уклоняется от ударов/снарядов, но НЕ от AoE; удерживайте для спринта ([mechanics/movement-controls.md](../mechanics/movement-controls.md)).
6. Флаконы заряжаются в бою, а не от убийств ([mechanics/flasks-charms.md](../mechanics/flasks-charms.md)).
7. Покупайте путевые камни (Waystone)/изучайте торговцев по мере их появления; Finn (Акт 1) управляет Currency Exchange.

## Кампания (Акты 1–4 + Интерлюдии)

- Следуйте основному квесту; побочные зоны дают постоянные бонусы к характеристикам (награды актов).
- Боссы актов гарантированно дропают uncut-камни и валюту для улучшений.
- Акт 3: появляется **Trial of Chaos**; Акт 2: **Trial of the Sekhemas** — любое из них открывает восхождение ([guides/ascendancy-unlock.md](ascendancy-unlock.md)).
- Ничего обязательного не пропускайте: Интерлюдии (0.3.0+) заменили сложность Cruel — один проход кампании до эндгейма.

## Первое восхождение

- Пройдите испытание сразу после Акта 2/3 — 4 очка восхождения — самый большой скачок силы за кампанию.
- Прочитайте таблицу восхождений вашего класса перед выбором: [classes/](../classes/) → файлы восхождений.

## Переход в эндгейм

- «Cataclysm's Wake» Дориани (Doryani) запускает эндгейм ([guides/endgame-progression.md](endgame-progression.md)).
- Смерть на картах забирает 10% опыта текущего уровня примерно с 65-го уровня.
