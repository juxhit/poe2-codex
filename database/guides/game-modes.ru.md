# Игровые режимы — SSF, Hardcore, кооп

> Базовые правила смерти/хардкора: [mechanics/death-trade-party.md](../mechanics/death-trade-party.md) · Этот файл: практические рекомендации по режимам.

## SSF (Solo Self-Found)

- Опция при создании персонажа; **торговли нет** — фармите всё самостоятельно ([правила смерти](../mechanics/death-trade-party.md)).
- Крафт-самодостаточность: освойте Reforging Bench 3→1 и крафт эссенциями рано — [crafting/](../crafting/index.md).
- Лучший сольный фарм: Ritual (уники/омены), remnants экспедиций (постоянные баффы), поддержание запаса путевых камней через трюк с неопознанным дропом — [mechanics/league-mechanics.md](../mechanics/league-mechanics.md), [guides/endgame-progression.md](endgame-progression.md).
- Желанные уники берутся из целевых источников (дроп реликвий в Sekhemas, ключи пиннаклов), а не из торговли — см. [bosses/pinnacle-bosses.md](../bosses/pinnacle-bosses.md).

## Hardcore (HC)

- Смерть навсегда → персонаж + инвентарь **мигрируют в Standard**; HC-сундук остаётся в HC для следующего персонажа; смерти на PvP тоже удаляют — см. [death-trade-party.md](../mechanics/death-trade-party.md).
- Опасные механики с одноразовым убийством, которые нужно уважать `(консенсус сообщества)`:
  - Массивные телеграфированные удары на эндгейм-тирах (аналоги Volatile Slam у Brambleghast; рефракционные лучи Uber-боссов актов — Doryani's Fist смертелен).
  - **Отражённый урон** и отражения шока в стиле Overcharge ([skills/support-gems.md](../skills/support-gems.md)).
  - Строение Honour в Sekhemas: 0 Honour = забег закончен — стакайте Honour Resistance ([mechanics/trials.md](../mechanics/trials.md)).
  - Цепочки Ritual Kings / Rite of the Nameless с нарастающими аффиксами.
- Рекомендуемый минимум перед эндгейм-HC: 75%+ резов, ~3k+ EHP, чары с иммунитетом к алиментам ([mechanics/flasks-charms.md](../mechanics/flasks-charms.md)).

## Партия / Кооп

| Правило | Детали |
|---|---|
| **Лут** | Общие видимые дропы; лидер задаёт распределение (FFA по умолчанию / Short ~5-секундное окно / Permanent) `(доступность режимов зависит от патча)` |
| **Бонус дропа** | Суммарно дропов ~+28% за каждого дополнительного участника; валюты/золота до +100% больше `(точное значение не подтверждено)`; количество с боссов = **минимум** игроков на старте И в конце боя — уход в середине боя снижает дроп |
| **XP** | Общий, взвешен в пользу игроков более высокого уровня; большие разрывы «голодуют» низкий уровень; партии до **6** человек |
| **Прогресс квестов/Атласа** | **Только лидер партии** получает зачёт квестов и очки Атласа — меняйте лидера на каждом путевом камне (Waystone) |
| **Порталы** | **Один портал на инстанс путевого камня** (не 6): выход с карты в середине может вас заблокировать; партия присоединяется через иконку портала у портрета лидера |
| **Сплит-скрин кооп** | PS5/Xbox shared-screen, кроссплей + кросспрогресс; оба игрока используют **один аккаунт**; game-share с двумя аккаунтами не поддерживается (на 0.5.5) |
| **Скейлинг монстров** | ~+50–60% к жизни за каждого дополнительного игрока `(не подтверждено)` — см. [death-trade-party.md](../mechanics/death-trade-party.md) |
