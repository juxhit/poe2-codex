# Гайд по выбору класса

> Полные данные классов: [classes/](../) · Восхождения: [ascendancies/](../ascendancies/)

| Класс | Атрибуты | Оружие | Стиль | Подходит новичку? |
|---|---|---|---|---|
| Warrior | Str | Булавы (2h/1h+щит) | Медленные удары, оглушения, активный блок | Да — живучий, прощает ошибки |
| Witch | Int | Жезлы + фокус | Армия приспешников, хаос-заклинания, проклятия | Да — безопасно, пассивный стиль |
| Ranger | Dex | Луки | Быстрые снаряды, яды, прыжки | Средне — хрупкий, мобильный |
| Sorceress | Int | Посохи/жезлы/фокусы | Стихийные заклинания, trigger-камни | Средне — стеклянная пушка |
| Mercenary | Str/Dex | Арбалеты + гранаты | Комбо с боеприпасами в стиле FPS | Средне — уникальный стиль |
| Monk | Dex/Int | Боевые посохи | Быстрый ближний бой, добивающие комбо, колокола | Сложно — высокая сложность исполнения |
| Huntress | Dex | Копья + парирование баклером | Гибриды ближнего боя/метания, детонации | Сложно — тайминг парирования |
| Druid | Str/Int | Талисманы (смена облика) | Bear/Wolf/Wyvern + заклинания | Средне — новинка 0.4.0 |

## Быстрые пути к решению

- Хотите **приспешников/питомцев**: Witch (или формы Druid; bear companion у Spirit Walker — это восхождение, а не выбор класса).
- Хотите **живучий ближний бой**: Warrior (Titan/Warbringer) или Smith of Kitava для самокованой экипировки.
- Хотите **кастование заклинаний**: Sorceress (Stormweaver = самый простой), Witch (Lich/Blood Mage для более рискованных стилей).
- Хотите **дальнобойный DPS**: Ranger (Deadeye для снарядов, Pathfinder для яда/снадобий) или Mercenary (комбо с арбалетом).
- Хотите **быстрый эффектный ближний бой**: Monk (Invoker для стихийного) — высокий потенциал, низкая защита.
- Хотите **необычные механики**: Mercenary Gemling (атрибуты), Acolyte of Chayula (Darkness), Chronomancer (время), Oracle (криты по предвидению).

## Шпаргалка по сочетаниям восхождений (0.5.x)

- Warrior → Titan (удары) / Warbringer (тотемы+пробитие брони) / Smith of Kitava (защита+огонь)
- Monk → Invoker (стихийный ближний бой) / Acolyte of Chayula (хаос+Darkness) / Martial Artist (клоны+колокола)
- Sorceress → Stormweaver (shock/chill) / Chronomancer (время) / Disciple of Varashta (джинны)
- Mercenary → Witchhunter (боссы) / Gemling (атрибуты) / Tactician (знамёна/баллисты)
- Ranger → Deadeye (снаряды) / Pathfinder (яд/флаконы)
- Witch → Infernalist (форма демона) / Blood Mage (цена жизни) / Lich (проклятия+ES)
- Huntress → Amazon (крит) / Ritualist (кольца/чары) / Spirit Walker (духи)
- Druid → Shaman (заклинания ярости) / Oracle (крит/предвидение)
