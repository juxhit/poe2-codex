# Настройки, хоткеи и производительность

> Источники: [Fextralife Controls](https://pathofexile2.wiki.fextralife.com/Controls), [официальная форумная тема о производительности](https://www.pathofexile.com/forum/view-thread/3800105). Правила движения: [mechanics/movement-controls.md](../mechanics/movement-controls.md)

## Управление

- **WASD — режим движения по умолчанию** (Settings → Input) — прицел остаётся на курсоре; click-to-move остаётся доступным для выбора. Выберите одно и придерживайтесь его.
- **Attack in Place**: стандартная привязка **Shift**; также индивидуально для умения через меню Skills → умение → **Skill Options → Attack in Place**.
- **«Always Attack without Moving»**: рекомендуется — кнопка умения атакует под курсором, а не идёт туда пешком.
- **Кувырок**: по умолчанию **Space** (переназначается); направление следует за WASD. Известная особенность: кувырок может направляться курсором, если отпустить WASD в середине кувырка.
- Смарт-каст / системы в стиле QWER: как отдельные режимы отсутствуют `(не подтверждено)` — используйте Skill Options для каждого умения.

## QoL-настройки

| Настройка | Рекомендация |
|---|---|
| Подписи предметов | **Alt** показывает; **Z** переключает постоянное отображение; установите «Toggle Label Visibility» → **Permanent**; включите «Use Highlight Key to pick up loot» |
| Полосы здоровья | «Always Highlight» → **Enemies Only**; «Show Mini Life Bar Above You» |
| Миникарта | Включите краевую миникарту в настройках UI |
| Подбор лута | **Лут-пылесоса не существует**; золото подбирается автоматически при проходе (радиус не настраивается) |

## Производительность (эндгейм: Breach/Delirium)

Самые тяжёлые настройки, в порядке затрат FPS:

1. **Global Illumination** — наибольшая единичная стоимость
2. **Shadows**
3. **Effects** — поток частиц в Breach/Delirium — главный убийца производительности

Частые исправления (проверены сообществом):

!!! tip "Исправление фризов после патчей"
    Очистите **ShaderCache** в `%APPDATA%\Path of Exile 2` (при закрытой игре), когда после патчей начинаются фризы. Установка **NVIDIA Shader Cache Size на 100 GB / Unlimited** и добавление папки шейдеров/кэша в **исключения Windows Defender** дополнительно снижают количество рекопиляций.

- Установите **NVIDIA Shader Cache Size на 100 GB / Unlimited**.
- Добавьте папку шейдеров/кэша в **исключения Windows Defender**.
- Переключите рендерер на **Vulkan**; включите апскейлинг **DLSS/FSR**; обновите драйверы GPU.
