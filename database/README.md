## Content ownership rules (no duplication)

- **mechanics/** — rules, formulas, caps, slot limits.
- **items/** — catalogs: bases, uniques, currency values.
- **crafting/** — how to roll/obtain: methods, currencies, recipes.
- **bosses/** — per-boss tactics and loot; access/progression lives in `mechanics/pinnacle-bosses.md`.
- **1.0/** — archive of pre-release facts/rumors; after the Dec 11, 2026 patch, verified facts migrate into main sections (checklist in [meta/changelog.md](meta/changelog.md)).
- **Anchors:** all files use `##`/`###` headers — deep-link like `skills/support-gems.md#system-rules` works on GitHub/Obsidian.
