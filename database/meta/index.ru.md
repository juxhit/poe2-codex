## Правила сопровождения

1. **Владение контентом** (без дублирования):
   - `mechanics/` — правила, формулы, капы, лимиты слотов.
   - `items/` — каталоги: базы, уникальные предметы, стоимости валюты.
   - `crafting/` — как получить/скрафтить: методы, валюты, рецепты.
   - `bosses/` — тактики и лут по каждому боссу; доступ/прогрессия остаются в `mechanics/pinnacle-bosses.md`.
2. **Рабочий процесс патча:** changelog.md → обновить затронутые файлы → заново проверить ссылки → обновить дату снимка в README.
3. **Миграция 1.0:** после патчноутов от Dec 11, 2026 перенести факты из `1.0/confirmed.md` в основные разделы (по чек-листу в changelog), оставив `1.0/` как архив.
4. **Метки неопределённости:** `(не подтверждено)` = единственный/слабый источник · `(нет данных)` = данные отсутствуют, с указанием, где их взять.
5. **Анкоры:** все файлы используют заголовки `##`/`###` — анкоры GitHub/Obsidian работают (в стиле `skills/support-gems.md#general-damage--cost--utility`) для глубоких ссылок на конкретные камни/боссов.
