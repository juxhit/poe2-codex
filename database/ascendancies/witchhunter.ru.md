# Witchhunter (Восхождение Mercenary)

- **Класс:** [Mercenary](../classes/mercenary.md)
- **Тематика:** Беспощадный инквизитор ортодоксии Templar, казнящий осквернённых — добивающий раненых, разбивающий концентрацию врагов и ограждающий себя ритуальной магией.
- **Механический стиль:** Добивание/казнь слабых по здоровью, механика «Concentration» (Witchbane/No Mercy), защита Sorcery Ward, взрывы трупов, гибкость пассивок по наборам оружия.
- **Испытание:** Любое (исторически называли Sekhemas)
- **Источник:** [poe2db.tw/us/Witchhunter](https://poe2db.tw/us/Witchhunter)

## Пассивные умения (14, 0.5.x)

| Умение | Эффект |
|---|---|
| Witchhunter | Стартовое умение Восхождения |
| Damage vs Low Life Enemies (×2 узла) | По 35% больше урона ударами по врагам на низком здоровье каждый |
| Cooldown Recovery Rate (×2 узла) | По 6% больше скорость восстановления перезарядки каждый |
| Armour and Evasion | На 15% больше броня и рейтинг уклонения |
| Area of Effect | Область действия на 8% больше |
| Pitiless Killer | Даёт Culling Strike |
| Judge, Jury, and Executioner | Даёт Decimating Strike |
| Witchbane | Максимум Concentration врагов равен 30% их максимума здоровья; вы срываете Concentration при попадании, равное нанесённому урону; реген 10%/с, если не терялось 5с |
| No Mercy | Наносите до 40% больше урона врагам в зависимости от их недостающей Concentration |
| Obsessive Rituals | Даёт умение Sorcery Ward; на 50% меньше брони и рейтинга уклонения |
| Ceremonial Ablution | Барьер Sorcery Ward может также поглощать физический урон и урон хаосом от ударов |
| Zealous Inquisition | 10% шанс, что убитые враги взорвутся, нанося 100% максимума здоровья в виде физического урона; удвоено против Undead и Demons |
| Weapon Master | 100 очков пассивных умений становятся очками умений набора оружия (Weapon Set Skill Points) |
