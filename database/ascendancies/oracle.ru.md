# Oracle (Восхождение Druid)

- **Класс:** [Druid](../classes/druid.md)
- **Тематика:** Oracle довела до совершенства Предвидение (Foresight) — вглядываясь в будущие таймлайны, чтобы предсказывать врагов, выделять пассивки из непройденных путей и принуждать судьбу к критической определённости.
- **Механический стиль:** Манипуляция таймлайнами — Entwined Realities/The Unseen Path (выделение обычно недостижимых не-keystone пассивок), Moment of Vulnerability (вытягивание «будущего состояния» врага в настоящее), Align Fate, гарантированные криты (Forced Outcome), крито-смягчающая защита (The Lesser Harm), поддержка тотемов (доп. максимум тотемов, Heartwood).
- **Испытание:** Любое (добавлено 0.4.0)
- **Источник:** [poe2db.tw/us/Oracle](https://poe2db.tw/us/Oracle)

## Пассивные умения (17, 0.5.x)

| Умение | Эффект |
|---|---|
| Oracle | Стартовое умение Восхождения |
| Passive Point (×2 узла) | Каждый даёт 1 очко пассивных умений (один помечен Mastery: Ultimatum) |
| Life and Mana Regeneration Rate | На 8% больше скорость регенерации здоровья и маны |
| Immobilisation Buildup | Накопление обездвиживания на 20% больше |
| Spell Damage | Урон заклинаниями на 12% больше |
| Totem Cast and Attack Speed | Заклинания тотемов получают 5% больше скорости каста; атаки тотемов получают 5% больше скорости атаки |
| Critical Damage Bonus on You | Удары по вам имеют на 12% уменьшенный бонус критического урона |
| Critical Hit Chance | Шанс критического удара на 12% больше |
| Entwined Realities | Не-Keystone пассивки в среднем радиусе (Medium Radius) выделенных Keystone могут выделяться без соединения с вашим деревом |
| The Unseen Path | «Walk the Paths Not Taken» (открывает/выделяет эксклюзивные узлы путей из ветвей других восхождений; по общественным источникам) |
| Harmony Within | Урон от ударов берётся из маны до здоровья, если текущая мана превышает текущее здоровье; на 15% меньше максимума здоровья и маны |
| Converging Paths | Даёт умение: Moment of Vulnerability (на враге, Primed для Stun/Electrocution/Freeze, создаёт Visage его будущего состояния) |
| Fateful Vision | Даёт умение: Align Fate |
| Heartwood | +1 к максимуму призванных тотемов; Тотемы умирают через 6 секунд после достижения их здоровьем 0 |
| The Lesser Harm | Шанс крита врагов против вас — Unlucky; урон врагов, бьющих вас, — Unlucky |
| Forced Outcome | «Неизбежные критические удары» (по общественным источникам: конвертирует/гарантирует критические удары) |

**Примечание:** Два текста эффектов узлов на poe2db являются заглушками («Walk the Paths Not Taken», «Inevitable Critical Hits»); точная формулировка помечена как низкодостоверная. Третье восхождение Druid ещё не раскрыто (см. [1.0/rumors.md](../1.0/rumors.md)).
