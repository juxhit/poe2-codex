# Pathfinder (Восхождение Ranger)

- **Класс:** [Ranger](../classes/ranger.md)
- **Тематика:** Алхимик джунглей, превращающая собственные фляги в оружие — швыряющая летучие снадобья, нагромождающая яд за пределами смертельных лимитов и перегоняющая всё, что пытается её замедлить.
- **Механический стиль:** Экономика фляг/зарядов (Enduring Elixirs), пять выданных умений броска Concoction (Explosive/Shattering/Fulminating/Acidic/Bleeding), двойной лимит стеков яда, доступ к пассивкам других классов (стартовые узлы Warrior/Sorceress), гибкость характеристик от Traveller's Wisdom.
- **Испытание:** Любое (исторически называли Chaos)
- **Источник:** [poe2db.tw/us/Pathfinder](https://poe2db.tw/us/Pathfinder)

## Пассивные умения (22, 0.5.x)

| Умение | Эффект |
|---|---|
| Pathfinder | Стартовое умение Восхождения |
| Poison Effect | Величина накладываемого вами яда на 12% больше |
| Skill Speed (×2 узла) | По 4% больше скорость умений каждый |
| Evasion | Рейтинг уклонения на 20% больше |
| Life Flask Charges | На 20% больше получаемых зарядов флака здоровья |
| Mana Flask Charges | На 20% больше получаемых зарядов флака маны |
| Passive Points (×2 узла) | Каждый даёт 1 очко пассивных умений |
| Running Assault | Невозможно получить Heavy Stunned во время спринта; на 30% меньше штраф скорости передвижения от использования умений при движении |
| Relentless Pursuit | Ваша скорость не подвержена замедлениям |
| Overwhelming Toxicity | Удваивает, сколько ваших ядов цель может иметь одновременно; на 50% меньше длительность яда |

| Enduring Elixirs | Эффекты флака здоровья не снимаются при заполнении Незарезервированного здоровья; эффекты флака здоровья не встают в очередь |

| Explosive Concoction | Даёт умение: Explosive Concoction |
| Shattering Concoction | Даёт умение: Shattering Concoction |
| Fulminating Concoction | Даёт умение: Fulminating Concoction |
| Acidic Concoction | Даёт умение: Acidic Concoction |
| Bleeding Concoction | Даёт умение: Bleeding Concoction |
