# Acolyte of Chayula (Восхождение Monk)

- **Класс:** [Monk](../classes/monk.md)
- **Тематика:** Монах, отдавший тело и разум Chayula, тьме Breach — обменивает Дух (Spirit) на сновидческий второй пул «Тьмы» (Darkness), поглощающий урон.
- **Механический стиль:** Пул ресурса Darkness (заменяет Spirit через Embrace the Darkness), масштабирование урона/сопротивления хаосом, Volatility, Remnants, умения в тематике Breach.
- **Испытание:** Любое (исторически называли Chaos)
- **Источник:** [poe2db.tw/us/Acolyte_of_Chayula](https://poe2db.tw/us/Acolyte_of_Chayula)
- **Примечание:** Переработано к 1.0 — Darkness становится Keystone; получает компаньона-боевой шест (см. [1.0/confirmed.md](../1.0/confirmed.md)).

## Пассивные умения (21, 0.5.x)

| Умение | Эффект |
|---|---|
| Lucid Dreaming | Стартовое умение Восхождения |
| Inner Turmoil | Получаете 1 Volatility при наложении стихийного состояния; Не получаете урона от Volatility |
| Unravelling | Даёт умение/пассивку Unravelling |
| Sap of Nightmares | Похищение жизни (Leech) восстанавливает также на основе урона хаосом, а не только физического |
| Chayula's Gift | +10% максимума сопротивления хаосом; Сопротивление хаосом удвоено |
| Waking Dream | Даёт умение: Into the Breach |
| Choice of Power | Remnants собираются с 50% большего расстояния, эффект на 50% больше; Пламя Chayula проявляется фиолетовым |
| Choice of Mana | Те же бонусы Remnant; Пламя проявляется синим |
| Choice of Life | Те же бонусы Remnant; Пламя проявляется красным |
| Embrace the Darkness | У вас нет Духа (Spirit); базовый максимум Darkness 100 (+10/уровень); Получаемый урон резервируется из Darkness до Здоровья/Энергетического щита; резервирование Darkness длится 5 секунд |
| Grasp of the Void | Даёт умение: Void Illusion |
| Deepening Shadows | +1% максимума Darkness за каждые 1% сопротивления хаосом |
| Archon of Chayula | Даёт умение: Archon of Chayula |

### Малые узлы
- Volatility — 10% шанс получить Volatility при убийстве
- Chaos Damage (×2) — по 11% больше урона хаосом каждый
- Leech — Похищение жизни на 11% больше
- Chaos Resistance — +7% к сопротивлению хаосом
- Skill Speed (×2) — по 4% больше скорости умений каждый
- Darkness (×2) — по +10% максимума Darkness каждый
- Получаете 4% урона в виде дополнительного урона хаосом
