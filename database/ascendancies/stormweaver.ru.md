# Stormweaver (Восхождение Sorceress)

- **Класс:** [Sorceress](../classes/sorceress.md)
- **Тематика:** Владычица бури, каждое заклинание которой трещит шоком и охлаждением, обрушивая стихийные последствия на всё, что навлечёт её гнев.
- **Механический стиль:** Формирователь шока/охлаждения (весь урон вносит вклад; двойное наложение шока/охлаждения), аптайм Arcane Surge, Elemental Storm на критах заклинаний, дополнительные лимиты умений.
- **Испытание:** Любое (исторически называли Sekhemas)
- **Источник:** [poe2db.tw/us/Stormweaver](https://poe2db.tw/us/Stormweaver)

## Пассивные умения (16, 0.5.x)

| Умение | Эффект |
|---|---|
| Stormweaver | Стартовое умение Восхождения |
| Mana Regeneration (×2 узла) | По 12% больше скорости регенерации маны каждый |
| Spell Critical Chance (×2 узла) | По 12% больше шанса критического удара заклинаниями каждый |
| Shock Chance (×2 узла) | По 20% больше шанс шока каждый |
| Chill Duration (×2 узла) | По 25% больше длительность охлаждения на врагах каждый |
| Remnant Range (×2 узла) | Remnants собираются с 25% большего расстояния каждый |
| Constant Gale | У вас есть Arcane Surge |
| Refracted Infusion | Сбор стихийной инфузии (Elemental Infusion) даёт другую, отличную стихийную инфузию |
| Force of Will | 20% получаемого урона берётся из маны до здоровья; эффект Arcane Surge увеличивается на 20% за каждые 10% недостающей маны |
| Tempest Caller | Даёт умение Elemental Storm; срабатывает от критических ударов заклинаниями |
| Multiplying Squalls | +2 к лимиту стихийных умений |
| Strike Twice | Цели могут подвергаться двум вашим шокам одновременно; шоки наносят на 25% меньше величины |
| Heavy Snows | Цели могут подвергаться двум охлаждениям одновременно; охлаждения могут замедлять до 35%; на 25% меньше величина охлаждения |
| Shaper of Storms | Весь урон от попаданий вносит вклад в шанс шока |
| Shaper of Winter | Весь урон от попаданий вносит вклад в величину охлаждения |
| Storm's Recollection | Remnants собираются с 50% большего расстояния; собранные Remnants появляются вновь через 3 секунды |
