# Deadeye (Восхождение Ranger)

- **Класс:** [Ranger](../classes/ranger.md)
- **Тематика:** Непревзойдённая меткая стрелочница, чьи стрелы не промахиваются дважды — дополнительные снаряды, ветряная стремительность и хирургическое исполнение меток.
- **Механический стиль:** Масштабирование количества/дистанции снарядов (Endless Munitions, Far Shot/Point Blank), Tailwind, удвоение зарядов ярости (Frenzy), клон Mirage Deadeye, синергия крита с потреблением меток (Bullseye).
- **Испытание:** Любое (исторически называли Sekhemas)
- **Источник:** [poe2db.tw/us/Deadeye](https://poe2db.tw/us/Deadeye)

## Пассивные умения (17, 0.5.x)

| Умение | Эффект |
|---|---|
| Deadeye | Стартовое умение Восхождения |
| Projectile Speed | Скорость снарядов на 10% больше |
| Skill Speed | Скорость умений на 4% больше |
| Mark Effect (×2 узла) | По 12% больше эффект ваших умений-меток каждый |
| Frenzy Charge Duration | Длительность зарядов ярости (Frenzy Charge) на 25% больше |
| Projectile Damage | Урон снарядами на 12% больше |
| Endless Munitions | Умения выпускают один дополнительный снаряд |
| Far Shot | Снаряды наносят больше урона от попаданий с дистанцией (0% в пределах 3.5м, до 20% после 7м) |
| Point Blank | Снаряды наносят на 20% больше урона от попаданий в пределах 3.5м, с уменьшением до 0% к 7м |
| Projectile Proximity Specialisation | Текст эффекта не показан на poe2db (специализация снарядов по близости) |
| Gathering Winds | Получаете Tailwind при использовании умения; теряете весь Tailwind при получении удара |
| Mirage Deadeye | Даёт умение Mirage Deadeye |
| Avidity | 50% шанс получить дополнительный заряд при получении заряда ярости (Frenzy Charge) |
| Thrilling Chase | Преимущества от потребления зарядов ярости имеют 50% шанс быть удвоенными |
| Called Shots | Даёт умение Called Shots |
| Bullseye | Накладываете 10 Critical Weakness на врагов при потреблении метки с них |

**Примечание:** Fextralife всё ещё перечисляет «Wind Ward» — отсутствует в текущих данных poe2db. Третье восхождение Ranger ещё не вышло (см. [1.0/rumors.md](../1.0/rumors.md)).
