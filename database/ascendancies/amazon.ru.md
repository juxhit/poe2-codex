# Amazon (Восхождение Huntress)

- **Класс:** [Huntress](../classes/huntress.md)
- **Тематика:** Мастер охоты, обученный до совершенства — точные критические удары, вскрытые слабости и атаки, усиленные стихийными всплесками.
- **Механический стиль:** Переполнение крита/точности (крит из избыточного шанса попадания), вскрытие Weakness против редких/уникальных врагов, система зарядов Elemental Surge (всплески Молнии/Огня/Холода), пересечение с флягами (Azmeri Brew), перераспределение уклонения (Stalking Panther).
- **Испытание:** Любое (исторически называли Sekhemas; Amazon было привязанным к Sekhemas восхождением патча 0.2)
- **Источник:** [poe2db.tw/us/Amazon](https://poe2db.tw/us/Amazon)

## Пассивные умения (16, 0.5.x)

| Умение | Эффект |
|---|---|
| Amazon | Стартовое умение Восхождения |
| Accuracy | Рейтинг точности на 12% больше |
| Skill Speed | Скорость умений на 4% больше |
| Elemental Damage | Стихийный урон на 12% больше |
| Flask Recovery | Восстановление здоровья и маны от фляг на 15% больше |
| Evasion | Рейтинг уклонения на 20% больше |
| Life Leech | Количество похищаемого здоровья на 12% больше |
| Critical Strike | Шанс попадания атаками может превышать 100%; получаете дополнительный шанс крита, равный 25% избыточного шанса попадания |
| Penetrate | Атаки вашим оружием получают добавленный физический урон, равный 25% рейтинга точности оружия |
| Predatory Instinct | Вскрываете Weakness против Rare и Unique врагов; на 50% больше урона против врагов с открытой слабостью (Open Weakness) |
| In for the Kill | На 20% больше скорость передвижения и на 40% больше скорость умений, пока враг с открытой слабостью (Open Weakness) в вашем Presence |
| Surging Avatar | Получаете на 1 меньше Lightning Surge при срабатывании Elemental Surge; потребление заряда срабатывает Elemental Surge, чтобы получить 2 Fire Surge и 2 Cold Surge |
| Elemental Surge | Даёт умение Elemental Surge; потребление заряда срабатывает его, чтобы получить 3 Lightning Surge |
| Azmeri Brew | Фляги здоровья также восстанавливают ману; фляги маны также восстанавливают здоровье |
| Stalking Panther | Уклонение от шлема, перчаток и ботинок удвоено; уклонение от нагрудника уменьшено вдвое |
| Mystic Harvest | Похищение здоровья (Life Leech) восстанавливает и от вашего стихийного урона, а не только физического |

**Примечание:** Fextralife перечисляет «Infused Avatar» — текущие данные poe2db показывают Surging Avatar.
