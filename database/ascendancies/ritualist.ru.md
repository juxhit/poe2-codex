# Ritualist (Восхождение Huntress)

- **Класс:** [Huntress](../classes/huntress.md)
- **Тематика:** Тёмная последовательница традиций Азмери — кровавые жертвы, осквернённая жизненная сила и шёпоты, требующие подношений.
- **Механический стиль:** Масштабирование от колец/амулетов (Mystic Attunement) с дополнительным слотом кольца, дополнительный слот талисмана + срабатывание талисманов без зарядов, Ritual Sacrifice (охота за головами без трупа), осквернённая жизненная сила Blood Boil, масштабирование восстановления на низком здоровье.
- **Испытание:** Любое (исторически называли Chaos; Ritualist было привязанным к Chaos восхождением патча 0.2)
- **Источник:** [poe2db.tw/us/Ritualist](https://poe2db.tw/us/Ritualist)

## Пассивные умения (17, 0.5.x)

| Умение | Эффект |
|---|---|
| Ritualist | Стартовое умение Восхождения |
| Reduced Mana | На 30% уменьшен максимум маны |
| Reduced Spirit | На 25% уменьшен Дух (Spirit) |
| Reduced Resistances | −20% ко всем стихийным сопротивлениям |
| Attributes | Характеристики на 3% больше |
| Charm Charges | На 15% больше получаемых зарядов талисманов |
| Life Recovery Rate | Скорость восстановления здоровья на 10% больше |
| Physical Damage | Физический урон на 15% больше |
| Movement Speed | Скорость передвижения на 3% больше |
| Mystic Attunement | На 25% больше бонусы от надетых колец и амулетов |
| Unfurled Finger | +1 слот кольца |
| Intricate Sigils | +1 слот талисманов; на 20% больше получаемых зарядов талисманов |
| Mind Phylacteries | Может потреблять 25% максимума маны для срабатывания талисманов без зарядов |
| Wildwood Persistence | На 10% больше скорость восстановления здоровья за каждые 5% недостающего Незарезервированного здоровья |
| Corrupted Lifeforce | Даёт умение Blood Boil; на 15% больше урона против врагов, поражённых Blood Boil |
| As the Whispers Demand | Даёт умение Ritual Sacrifice (взять голову без трупа) |
| Devotion to the King | Даёт умение Queen's Procession |
