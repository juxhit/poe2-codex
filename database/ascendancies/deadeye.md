# Deadeye (Ranger Ascendancy)

- **Class:** [Ranger](../classes/ranger.md)
- **Theme:** A peerless markswoman whose arrows never miss twice — extra projectiles, wind-swiftness, and surgical mark execution.
- **Mechanical identity:** Projectile count/distance scaling (Endless Munitions, Far Shot/Point Blank), Tailwind, Frenzy charge doubling, Mirage Deadeye clone, mark-consumption crit synergy (Bullseye).
- **Trial:** Any (Sekhemas historically cited)
- **Source:** [poe2db.tw/us/Deadeye](https://poe2db.tw/us/Deadeye)

## Passive nodes (17, 0.5.x)

| Node | Effect |
|---|---|
| Deadeye | Ascendancy start node |
| Projectile Speed | 10% increased Projectile Speed |
| Skill Speed | 4% increased Skill Speed |
| Mark Effect (×2 nodes) | 12% increased Effect of your Mark Skills each |
| Frenzy Charge Duration | 25% increased Frenzy Charge Duration |
| Projectile Damage | 12% increased Projectile Damage |
| Endless Munitions | Skills fire one additional Projectile |
| Far Shot | Projectiles deal more hit damage with distance (0% within 3.5m, up to 20% after 7m) |
| Point Blank | Projectiles deal 20% more hit damage within 3.5m, scaling to 0% by 7m |
| Projectile Proximity Specialisation | Effect text not shown on poe2db (proximity-based projectile specialisation) |
| Gathering Winds | Gain Tailwind on Skill use; lose all Tailwind when Hit |
| Mirage Deadeye | Grants the skill Mirage Deadeye |
| Avidity | 50% chance when you gain a Frenzy Charge to gain an additional one |
| Thrilling Chase | Benefits from consuming Frenzy Charges have 50% chance to be doubled |
| Called Shots | Grants the skill Called Shots |
| Bullseye | Apply 10 Critical Weakness to enemies when consuming a Mark on them |

**Note:** Fextralife still lists "Wind Ward" — not in current poe2db data. Ranger's third ascendancy is not yet released (see [1.0/rumors.md](../1.0/rumors.md)).
