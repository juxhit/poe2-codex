# Titan (Восхождение Warrior)

- **Класс:** [Warrior](../classes/warrior.md)
- **Тематика:** Огромный родовой колосс из рода каруи-великанов — больше слэмы, больше оглушения, больше тело. Обменивает ловкость на чистую массу.
- **Механический стиль:** Слэм-умения (афтершоки, Ancestral Boosting), накопление оглушения, масштабирование от малых пассивных умений, здоровье/броня, уникальная утилита «сундук в инвентаре».
- **Испытание:** Любое (нет фиксированной привязки в текущих патчах; исторически называли Sekhemas)
- **Источник:** [poe2db.tw/us/Titan](https://poe2db.tw/us/Titan)

## Пассивные умения (14, 0.5.x)

| Умение | Эффект |
|---|---|
| Titan | Стартовое умение Восхождения |
| Slam Area of Effect | Слэм-умения имеют область действия на 8% больше |
| Stun Buildup | Накопление оглушения на 18% больше |
| Strength | Сила на 4% больше |
| Life Regeneration | Восстановление 0.5% максимума здоровья в секунду |
| Armour | Броня на 20% больше |
| Earthbreaker | 25% шанс того, что слэм-умения, использованные вами лично, вызовут дополнительный афтершок (вторичную волну) |
| Ancestral Empowerment | Каждое второе слэм-умение, использованное вами лично, получает Ancestral Boost |
| Mountain Splitter | Каждое третье слэм-умение, не создающее Fissures, вызывает 3 дополнительных афтершока (впереди и по сторонам) |
| Crushing Impacts | Ваши удары — Crushing Blows; на 25% больше урона по врагам в Heavy Stunned |
| Hulking Form | Эффект малых пассивных умений на 50% больше |
| Colossal Capacity | Носите сундук, добавляющий 20 слотов инвентаря |
| Mysterious Lineage | На 15% больше максимума здоровья |
| Stone Skin | На 50% больше брони от надетого нагрудного доспеха |

**Примечание:** Fextralife всё ещё перечисляет «Surprising Strength» — вероятно, заменено на Mountain Splitter в недавнем патче (не подтверждено, в каком именно).
