# Gemling Legionnaire (Mercenary Ascendancy)

- **Class:** [Mercenary](../classes/mercenary.md)
- **Theme:** An elite soldier of the Gemling Legion, surgically implanted with thaumaturgical gems — living proof that attributes and gem quality can be pushed beyond human limits.
- **Mechanical identity:** Attribute stacking (repeatable attribute nodes, requirements met by highest attribute, doubled attribute bonuses), +skill levels by attribute requirement, gem-quality effects, socketed-support-gem color payoffs, max resist per gems, barrier skill.
- **Trial:** Any (Chaos historically cited)
- **Source:** [poe2db.tw/us/Gemling_Legionnaire](https://poe2db.tw/us/Gemling_Legionnaire)

## Passive nodes (15, 0.5.x)

| Node | Effect |
|---|---|
| Gemling Legionnaire | Ascendancy start node |
| Skill Gem Quality | +2% to Quality of all Skills (appears on multiple branch points) |
| Reduced Attribute Requirements | Equipment and Skill Gems have 4% reduced Attribute Requirements (repeatable) |
| Attributes | 3% increased Attributes (repeatable) |
| Essence of Virtue | Grants skill Virtuous Barrier; base maximum of 3 Gemling barrier stacks |
| Implanted Gems | Grouping node (effect text not shown on poe2db) |
| Bolstering Implants | +2 to Level of all Skills with a Strength requirement |
| Motoric Implants | +2 to Level of all Skills with a Dexterity requirement |
| Neurological Implants | +2 to Level of all Skills with an Intelligence requirement |
| Gem Studded | Per most-numerous socketed support gem color: Red = hits against you have no crit damage bonus; Blue = 30% less skill cost; Green = 40% less movement speed penalty from skills while moving |
| Advanced Thaumaturgy | Gem Quality grants Socketed Skills an additional effect |
| Enhanced Effectiveness | 20% less Attributes; inherent bonuses gained from Attributes are doubled |
| Adaptive Capability | Attribute Requirements of Gems can be satisfied by your highest Attribute |
| Integrated Efficiency | Per connected support gem: Red = 20% increased damage; Blue = 20% increased crit chance; Green = 6% increased skill speed |
| Thaumaturgical Infusion | +1% maximum resistance per 3 socketed support gems of matching color (Blue→Cold, Red→Fire, Green→Lightning) |

**Note:** Fextralife lists "Crystalline Potential" — not in current poe2db data.
