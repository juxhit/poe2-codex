# Titan (Warrior Ascendancy)

- **Class:** [Warrior](../classes/warrior.md)
- **Theme:** An enormous ancestral colossus of Karui giant lineage — bigger slams, bigger stun, bigger body. Trades agility for sheer mass.
- **Mechanical identity:** Slam skills (aftershocks, Ancestral Boosting), stun build-up, small-passive scaling, life/armour, unique chest-inventory utility.
- **Trial:** Any (no fixed binding in current patches; Sekhemas historically cited)
- **Source:** [poe2db.tw/us/Titan](https://poe2db.tw/us/Titan)

## Passive nodes (14, 0.5.x)

| Node | Effect |
|---|---|
| Titan | Ascendancy start node |
| Slam Area of Effect | Slam Skills have 8% increased Area of Effect |
| Stun Buildup | 18% increased Stun Buildup |
| Strength | 4% increased Strength |
| Life Regeneration | Regenerate 0.5% of maximum Life per second |
| Armour | 20% increased Armour |
| Earthbreaker | 25% chance for Slam Skills you use yourself to cause an additional Aftershock |
| Ancestral Empowerment | Every second Slam Skill you use yourself is Ancestrally Boosted |
| Mountain Splitter | Every third Slam skill that doesn't create Fissures causes 3 additional Aftershocks (ahead and to each side) |
| Crushing Impacts | Your Hits are Crushing Blows; 25% more damage against Heavy Stunned enemies |
| Hulking Form | 50% increased effect of Small Passive Skills |
| Colossal Capacity | Carry a Chest which adds 20 Inventory Slots |
| Mysterious Lineage | 15% more Maximum Life |
| Stone Skin | 50% more Armour from Equipped Body Armour |

**Note:** Fextralife still lists "Surprising Strength" — likely replaced by Mountain Splitter in a recent patch (unconfirmed which patch).
