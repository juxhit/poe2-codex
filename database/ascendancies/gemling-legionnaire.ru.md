# Gemling Legionnaire (Восхождение Mercenary)

- **Класс:** [Mercenary](../classes/mercenary.md)
- **Тематика:** Элитный солдат Gemling Legion, хирургически имплантированный тауматургическими камнями — живое доказательство того, что характеристики и качество камней можно раздвинуть за пределы человеческих возможностей.
- **Механический стиль:** Накопление характеристик (повторяемые узлы характеристик, требования выполняются самой высокой характеристикой, удвоенные бонусы характеристик), +уровни умений по требованию характеристики, эффекты качества камней, бонусы за цвет вставленных камней поддержки, максимальные сопротивления за камни, умение-барьер.
- **Испытание:** Любое (исторически называли Chaos)
- **Источник:** [poe2db.tw/us/Gemling_Legionnaire](https://poe2db.tw/us/Gemling_Legionnaire)

## Пассивные умения (15, 0.5.x)

| Умение | Эффект |
|---|---|
| Gemling Legionnaire | Стартовое умение Восхождения |
| Skill Gem Quality | +2% к качеству всех умений (встречается в нескольких точках ветвей) |
| Reduced Attribute Requirements | Снаряжение и камни умений имеют на 4% уменьшенные требования характеристик (повторяемо) |
| Attributes | Характеристики на 3% больше (повторяемо) |
| Essence of Virtue | Даёт умение Virtuous Barrier; базовый максимум 3 стека барьера Gemling |
| Implanted Gems | Группирующий узел (текст эффекта не показан на poe2db) |
| Bolstering Implants | +2 к уровню всех умений с требованием к Силе |
| Motoric Implants | +2 к уровню всех умений с требованием к Ловкости |
| Neurological Implants | +2 к уровню всех умений с требованием к Интеллекту |
| Gem Studded | За самый многочисленный цвет вставленных камней поддержки: Красный = удары по вам не имеют бонуса критического урона; Синий = на 30% меньше стоимость умений; Зелёный = на 40% меньше штраф скорости передвижения от умений при движении |
| Advanced Thaumaturgy | Качество камня даёт вставленным умениям дополнительный эффект |
| Enhanced Effectiveness | На 20% меньше характеристик; врождённые бонусы от характеристик удвоены |
| Adaptive Capability | Требования характеристик камней могут быть удовлетворены вашей самой высокой характеристикой |
| Integrated Efficiency | За каждый связанный камень поддержки: Красный = на 20% больше урона; Синий = на 20% больше шанс крита; Зелёный = на 6% больше скорость умений |
| Thaumaturgical Infusion | +1% максимального сопротивления за каждые 3 вставленных камня поддержки соответствующего цвета (Синий→Холод, Красный→Огонь, Зелёный→Молния) |

**Примечание:** Fextralife перечисляет «Crystalline Potential» — отсутствует в текущих данных poe2db.
