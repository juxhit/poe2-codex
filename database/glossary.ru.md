# Глоссарий

> Сленг сообщества и краткие обозначения механик. Подробные механики: [mechanics/](mechanics/index.md)

## Общий сленг

| Термин | Значение |
|---|---|
| **AoE** | Область действия эффекта |
| **DoT** | Урон с течением времени |
| **DPS** | Урон в секунду |
| **EHP** | Эффективный запас здоровья (сколько чистого урона вы выживаете после всех снижений урона) |
| **More vs Increased** | "Increased/Reduced" = аддитивно с источниками той же характеристики; "More/Less" = мультипликативно — см. [mechanics/life-mana-es.md](mechanics/life-mana-es.md) |
| **CC** | Контроль (оглушение, заморозка, обездвиживание…) |
| **Clear** | Скорость зачистки монстров на картах |
| **Single target / ST** | Урон, сфокусированный на боссах |
| **QoL** | Удобство использования (Quality of Life) |
| **League starter** | Билд, выбираемый для дешёвого старта лиги с новой экономикой |
| **SSF** | Одиночная игра без торговли (Solo Self-Found) |
| **HC** | Хардкор (перманентная смерть) |
| **RIP** | Смерть хардкорного персонажа |
| **Alt-tab / overlay** | Проверка цен вне игрового окна |
| **RMT** | Торговля за реальные деньги (бан) |
| **Mirror-tier** | Предмет, стоимость которого приближается к Mirror of Kalandra |
| **Crafting bench** | Термин PoE1; в PoE2 используются станки Reforging/Salvage + прямая валюта — см. [crafting/](crafting/index.md) |

## Бой и характеристики

| Термин | Значение |
|---|---|
| **Ailment Threshold** | Скрытая характеристика против наложения состояний; у игроков = половина максимума здоровья — см. [mechanics/ailments.md](mechanics/ailments.md) |
| **Ignite / Shock / Chill / Freeze** | Огненный DoT (20% от удара) / +получаемый урон / замедление действий / блокировка действий |
| **Bleed / Poison** | Физический DoT (удваивается при движении) / хаос-DoT (по умолчанию один стак) — оба обходят ES |
| **Electrocute** | Блокировка действий от молнии (через накопление шкалы) |
| **Heavy Stun** | Заполнение шкалы оглушения до 100% → несколько секунд бездействия |
| **Pin / Immobilise** | На основе снарядов / зонтичное состояние (Heavy Stun, Pin, Freeze, Electrocute) |
| **Culling Strike** | Мгновенное убийство врагов ниже 10% здоровья |
| **Execute** | Урон по целям с низким здоровьем |
| **Armour Break / Fully Broken** | Снижение брони (может уходить ниже 0 с Imploding Impacts) |
| **Exposure** | Дебафф, снижающий сопротивления (−Resistance) |
| **Wither** | Стакающийся дебафф получаемого урона хаосом |
| **Onslaught** | Бафф к скорости атаки/кастования/передвижения |
| **Tailwind** | Бафф скорости действий (Deadeye) |
| **Leech** | Восполнение в течение 1 с, масштабируется от удара; один эффект на ресурс — см. [mechanics/leech.md](mechanics/leech.md) |
| **Recoup** | Отложенное восполнение процента полученного/нанесённого урона |
| **Lucky / Unlucky** | Бросок дважды, берётся лучший/худший результат — см. [mechanics/damage-types.md](mechanics/damage-types.md) |
| **Entropy** | Детерминированная система уклонения |
| **Presence** | Радиус вокруг вас для эффектов, подобных аурам |
| **Reservation** | Постоянное резервирование Spirit (или систем Darkness/Infernal Flame) |

## Предметы и экономика

| Термин | Значение |
|---|---|
| **T16 / T1** | Тир Waystone (сложность эндгейма, 1–16) |
| **Ilvl** | Уровень предмета (ограничивает тиры модификаторов) |
| **Fractured** | Навсегда зафиксированный модификатор — см. [crafting/fractured-desecration.md](crafting/fractured-desecration.md) |
| **Desecrated** | Эксклюзивный модификатор лиги Abyss |
| **Forgemarked** | Модификатор лиги 1.0, выбранный для постоянной фиксации (fracture) |
| **Magic find / IIR / IIQ** | Увеличения редкости / количества предметов |
| **Wsd / Waystone drop chance** | Стат поддержания карт |
| **Pinnacle** | Тир эндгейм-боссов (Arbiter, Xesht, King in the Mists…) |
| **Barya / Ultimatum** | Ключи испытаний (Sekhemas / Chaos) |
| **Splinter** | Фрагмент в стаке 1/300 → ключ от босса |
| **Base** | Базовый тип предмета |
| **TTFK** | Сокращение для Time-Lost джевелов `(употребление в сообществе различается)` |

## Билды

| Термин | Значение |
|---|---|
| **CoC** | Cast on Critical (мета-камень) — см. [skills/meta-gems.md](skills/meta-gems.md) |
| **CoD / CoA / CoMD** | Cast on Dodge / Ailment / Minion Death |
| **Totem / Minion / Herald** | Постоянные (персистентные) стили игры |
| **Triggerbots** | Запрещённая автоматизация; не путать с мета-камнями |
| **PPT** | Очки пассивок набора оружия (Weapon Set Passive Points) |
| **Ascendancy** | Вознесение — подкласс класса, выбираемый через испытания |
| **Uber** | Сильнейшая версия босса (Uber-боссы актов, Ubers = пинакл-варианты) |
