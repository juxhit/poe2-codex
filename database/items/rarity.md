# Item Rarity

> Sources: [poe2db — Items](https://poe2db.tw/us/Items), [Fextralife Weapons](https://pathofexile2.wiki.fextralife.com/Weapons), [poe2db 0.5.0](https://poe2db.tw/us/Version_0.5.0)

| Rarity | Mod count | Notes |
|---|---|---|
| **Normal** | 0 explicit | White; Orb of Transmutation → Magic |
| **Magic** | 1–2 explicit | 2nd mod via Orb of Augmentation |
| **Rare** | up to 6 explicit | Exalted Orbs add up to the 6-mod cap |
| **Unique** | fixed handcrafted mods | Distinct artwork; not necessarily better than Rares; Vaal-corruptible |

## Implicits

- Every base type carries its own implicit modifier (e.g. Ruby Ring "+20–30% Fire Resistance", Veridical Chain "+30–40 Runic Ward"); special bases get multi-implicit **Runemastered** variants (Lv65).

## Slot-shifter bases (0.5.x twist)

- **Dusk / Gloam / Penumbra / Tenebrous** ring & amulet bases trade prefix vs suffix allowance (e.g. Penumbra Ring: +2 prefix, −2 suffix).

## 0.5.0 notes

- **Waystones must be identified** to activate.
- Currency comes in **base / Greater / Perfect** grades (Greater/Perfect need min mod levels 35/50 on the target item).
- New defence layer **Runic Ward** appears as an implicit on some armour bases.
- Smith of Kitava restricts his body armour to Normal (white) — see [ascendancies/smith-of-kitava.md](../ascendancies/smith-of-kitava.md).
