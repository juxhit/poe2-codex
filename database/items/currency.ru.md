# Каталог валюты (0.5.x)

> Источники: [poe2db — Stackable Currency](https://poe2db.tw/us/Stackable_Currency), [poe2db 0.5.0](https://poe2db.tw/us/Version_0.5.0). Применение в крафте: [crafting/](../crafting/index.md).

## Основные сферы

| Валюта | Эффект |
|---|---|
| Orb of Transmutation (Greater/Perfect) | Обычный → Магический, 1 свойство |
| Orb of Augmentation (Greater/Perfect) | Добавляет свойство Магическому предмету |
| Regal Orb (Greater/Perfect) | Магический → Редкий, +1 свойство |
| Exalted Orb (Greater/Perfect) | Добавляет случайное свойство Редкому |
| Chaos Orb (Greater/Perfect) | Перескатывает одно случайное свойство Редкого |
| Orb of Alchemy | Обычный/Магический → Редкий с 4 свойствами |
| Orb of Annulment | Удаляет случайное свойство |
| **Fracturing Orb** | Фиксирует случайное свойство Редкого с 4+ свойствами |
| Divine Orb | Перескатывает числовые значения свойств |
| Orb of Chance | Обычный → случайный Уникальный предмет этой базы, иначе уничтожает его |
| Mirror of Kalandra | Создаёт Mirrored (дублированную) копию |
| **Hinekora's Lock** | Предвидит результат следующей использованной валюты |
| Jeweller's Orb (Lesser/Greater/Perfect) | Задаёт Skill Gem 3/4/5 слотов поддержки |
| Artificer's Orb | Добавляет слот Augment (руны) в оружие/броню |
| Orb of Extraction | Извлекает Augment из снаряжения (уничтожает снаряжение) |

## Валюта качества

Blacksmith's Whetstone (боевое оружие) · Arcanist's Etcher (жезл/посох/скипетр) · Armourer's Scrap (броня) · Glassblower's Bauble (флаконы) · Gemcutter's Prism (камни) · Scroll of Wisdom (опознание) · Cryptic Key (доп. открытие сильных ящиков)

## Семейство Vaal

| Валюта | Эффект |
|---|---|
| Vaal Orb | Портит / непредсказуемо изменяет предмет |
| Architect's Orb | Изменить-или-уничтожить для испорченного снаряжения/джевелов |
| Crystallised Corruption | То же для испорченных камней умений |
| Core Destabiliser | Изменяет Soul Core (шанс уничтожения; может создавать Ancient Soul Cores) |
| Ancient Infuser | Изменяет + портит Tablet |
| Vaal Cultivation Orb | Перескатывает Vaal-уникальные предметы / заменяет Уникальные предметы испорченными |
| Orbs of Sacrifice (Yaomac's/Kopec's/Kamasa's/Yugul's) | Улучшают зачарование порчи (оружие/колчан, броня, украшения, джевел) — удаляют случайное свойство |
| Vaal Armourer's/Blacksmith's/Arcanist's/Catalysing Infuser | Качество до +10% сверх максимума, шанс испортить |

## Эссенции

Ступени Lesser → Normal → Greater (Магический→Редкий с гарантированным свойством); **Perfect** заменяет свойство на Редких. Полный список/эффекты: [crafting/essences.md](../crafting/essences.md). Особые: Hysteria, Delirium, Horror, Insanity, the Abyss, the Breach.

## Омены

Манипуляторы крафта из лиг Ritual/Abyss — полный список: [crafting/omens.md](../crafting/omens.md). 0.5.0 добавляет Chaotic Effectiveness; омены Chaotic Rarity/Quantity/Monsters инвертированы (предотвращают свой тип).

## Катализаторы (качество украшений/джевелов, Genesis Tree)

Flesh (жизнь) · Neural (мана) · Carapace (защиты) · Uul-Netol's (физ.) · Xoph's (огонь) · Tul's (холод) · Esh's (молния) · Chayula's (хаос) · Reaver (атака) · Sibilant (кастер) · Skittering (скорость) · Adaptive (характеристики) · Necrotic (приспешники) — каждый с вариантом **Refined**, ориентированным на джевелы. 0.5.0 добавляет 12 катализаторов для джевелов.

## Сплавы (0.5.0 — удаляют случайное свойство, добавляют гарантированное свойство только из сплавов)

Runic (Рунный барьер) · Adaptive · Protective · Expansive · Swift · Cyclonic · Prismatic · Mystic · Sovereign · Celestial · Transcendent · The Runebinder's · The Runefather's (всего 13). Подробности: [crafting/runeforging.md](../crafting/runeforging.md).
