# Currency Catalog (0.5.x)

> Sources: [poe2db — Stackable Currency](https://poe2db.tw/us/Stackable_Currency), [poe2db 0.5.0](https://poe2db.tw/us/Version_0.5.0). Crafting usage: [crafting/](../crafting/index.md).

## Core orbs

| Currency | Effect |
|---|---|
| Orb of Transmutation (Greater/Perfect) | Normal → Magic, 1 modifier |
| Orb of Augmentation (Greater/Perfect) | Adds a mod to a Magic item |
| Regal Orb (Greater/Perfect) | Magic → Rare, +1 mod |
| Exalted Orb (Greater/Perfect) | Adds a random mod to a Rare |
| Chaos Orb (Greater/Perfect) | Rerolls one random mod on a Rare |
| Orb of Alchemy | Normal/Magic → Rare with 4 mods |
| Orb of Annulment | Removes a random mod |
| **Fracturing Orb** | Locks a random mod on a Rare with 4+ mods |
| Divine Orb | Rerolls numeric values of mods |
| Orb of Chance | Normal → random Unique of that base, else destroys it |
| Mirror of Kalandra | Creates a Mirrored (duped) copy |
| **Hinekora's Lock** | Foresees the result of the next currency used |
| Jeweller's Orb (Lesser/Greater/Perfect) | Sets Skill Gem to 3/4/5 support sockets |
| Artificer's Orb | Adds an Augment (rune) socket to weapon/armour |
| Orb of Extraction | Salvages an Augment from gear (destroys the gear) |

## Quality currency

Blacksmith's Whetstone (martial weapons) · Arcanist's Etcher (wand/staff/sceptre) · Armourer's Scrap (armour) · Glassblower's Bauble (flasks) · Gemcutter's Prism (gems) · Scroll of Wisdom (identify) · Cryptic Key (extra strongbox open)

## Vaal family

| Currency | Effect |
|---|---|
| Vaal Orb | Corrupts / unpredictably modifies an item |
| Architect's Orb | Modify-or-destroy on Corrupted equipment/jewels |
| Crystallised Corruption | Same, for Corrupted Skill Gems |
| Core Destabiliser | Modifies a Soul Core (chance to destroy; can make Ancient Soul Cores) |
| Ancient Infuser | Modifies + corrupts a Tablet |
| Vaal Cultivation Orb | Re-rolls Vaal Uniques / swaps Uniques for corrupted ones |
| Orbs of Sacrifice (Yaomac's/Kopec's/Kamasa's/Yugul's) | Upgrade a Corruption enchantment (weapon/quiver, armour, jewelry, jewel) — removes a random mod |
| Vaal Armourer's/Blacksmith's/Arcanist's/Catalysing Infuser | Quality up to +10% over max, chance to corrupt |

## Essences

Tiers Lesser → Normal → Greater (Magic→Rare with a guaranteed mod); **Perfect** replaces a mod on Rares. Full list/effects: [crafting/essences.md](../crafting/essences.md). Special: Hysteria, Delirium, Horror, Insanity, the Abyss, the Breach.

## Omens

Craft manipulators from Ritual/Abyss — full list: [crafting/omens.md](../crafting/omens.md). 0.5.0 adds Chaotic Effectiveness; Chaotic Rarity/Quantity/Monsters omens inverted (prevent their type).

## Catalysts (jewellery/jewel quality, Genesis Tree)

Flesh (Life) · Neural (Mana) · Carapace (defences) · Uul-Netol's (Phys) · Xoph's (Fire) · Tul's (Cold) · Esh's (Lightning) · Chayula's (Chaos) · Reaver (Attack) · Sibilant (Caster) · Skittering (Speed) · Adaptive (Attributes) · Necrotic (Minions) — each with a **Refined** variant targeting jewels. 0.5.0 adds 12 jewel catalysts.

## Alloys (0.5.0 — remove a random mod, add a guaranteed alloy-only mod)

Runic (Runic Ward) · Adaptive · Protective · Expansive · Swift · Cyclonic · Prismatic · Mystic · Sovereign · Celestial · Transcendent · The Runebinder's · The Runefather's (13 total). Details: [crafting/runeforging.md](../crafting/runeforging.md).
