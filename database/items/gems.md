# Gems — Uncut Skills, Supports & Lineage

> Sources: [poe2db — Skill Gems](https://poe2db.tw/us/Skill_Gems), [poe2db 0.5.0](https://poe2db.tw/us/Version_0.5.0), [Fextralife Gemcutting](https://pathofexile2.wiki.fextralife.com/Gemcutting). System overview: [mechanics/index.md](../mechanics/index.md)

## Uncut gems

- **Uncut Skill Gems / Uncut Support Gems** drop in tiered versions gating by character level.
- Tier names: Rough / Ordinary / Refined / Polished / Superior / Perfect / Exceptional / Flawless — roughly level 1/7/14/22/30/38/46/54+ `(unconfirmed exact thresholds)`.
- Gem levels run 1–20; Gemcutter's Prism adds quality (+1% per quality); **Thaumaturgic Flux** upgrades skill gems to levels 5–20.
- Examples of min levels: Spark (1), Fireball (3), Hammer of the Gods (13).

## Categories

- **Skill Gems** — per weapon family + Elemental/Occult
- **Support Gems** — socket directly into skill gems; socket count via Jeweller's Orbs (Lesser/Greater/Perfect → 3/4/5 sockets)
- **Meta Skill Gems** — interact with Meta/Energy systems (Invoker's Soul Springs Eternal)
- **Spirit Gems** — spirit-reserved persistent skills
- **Lineage Supports** — 22 new in 0.5.0 (e.g. Vruun's Inevitability, Vorana's Siege, Uhtred's Constellation)

## 0.5.0 notable changes

- Seal mechanics standardised (Unleash/Expand/Salvo/Freezing Salvo).
- New Minion Splash I/II Strength supports.
- Infernal Legion III & Shock Conduction II removed; Overextend removed.
- Keystone-adjacent passives reworked: Vaal Pact (50% more leech / 67% less speed / no instant leech), Ancestral Bond (doubles totem limit), Trusted Kinship reworked.
