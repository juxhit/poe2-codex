# Камни — Неогранённые камни (Uncut Gems), камни поддержки (Support Gems) и Lineage

> Источники: [poe2db — Skill Gems](https://poe2db.tw/us/Skill_Gems), [poe2db 0.5.0](https://poe2db.tw/us/Version_0.5.0), [Fextralife Gemcutting](https://pathofexile2.wiki.fextralife.com/Gemcutting). Обзор системы: [mechanics/index.md](../mechanics/index.md)

## Неогранённые камни (Uncut Gems)

- **Uncut Skill Gems / Uncut Support Gems** выпадают в версиях по ступеням, привязанных к уровню персонажа.
- Названия ступеней: Rough / Ordinary / Refined / Polished / Superior / Perfect / Exceptional / Flawless — примерно уровни 1/7/14/22/30/38/46/54+ `(не подтверждено — точные пороги)`.
- Уровни камней 1–20; Gemcutter's Prism добавляет качество (+1% за единицу качества); **Thaumaturgic Flux** повышает камни умений до уровней 5–20.
- Примеры минимальных уровней: Spark (1), Fireball (3), Hammer of the Gods (13).

## Категории

- **Skill Gems** — по семействам оружия + Elemental/Occult
- **Камни поддержки (Support Gems)** — вставляются прямо в камни умений; число слотов через Jeweller's Orbs (Lesser/Greater/Perfect → 3/4/5 слотов)
- **Meta Skill Gems** — взаимодействуют с системами Meta/Энергии (Invoker's Soul Springs Eternal)
- **Spirit Gems** — постоянные умения, резервирующие Дух
- **Lineage Supports** — 22 новых в 0.5.0 (например, Vruun's Inevitability, Vorana's Siege, Uhtred's Constellation)

## Заметные изменения 0.5.0

- Механика печатей (Seals) стандартизирована (Unleash/Expand/Salvo/Freezing Salvo).
- Новые камни поддержки Minion Splash I/II (требуют Силы).
- Удалены Infernal Legion III и Shock Conduction II; удалён Overextend.
- Переработаны пассивки возле кейстоунов: Vaal Pact (на 50% больше вампиризма / на 67% меньше скорости / нет мгновенного вампиризма), Ancestral Bond (удваивает лимит тотемов), Trusted Kinship переработана.
