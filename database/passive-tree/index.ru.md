# Древо пассивных умений

> Снимок 2026-11-17, 0.5.x. Реворк 1.0 — 11 декабря 2026 — см. [1.0/confirmed.md](../1.0/confirmed.md)
>
> Файлы: этот обзор · [keystones.md](keystones.md) (ключевые пассивки + anointing/instilling)

## Основы навигации

- Древо разбито на **стартовые зоны атрибутов** (Сила/Ловкость/Инт/гибриды), расходящиеся наружу; кластеры выстраиваются в «шоссе» и «колёса».
- **Очки наборов оружия (Weapon Set Skill Points, WSP)**: часть наград за квесты даёт очки наборов оружия (всего 25 за кампанию — см. [guides/campaign-quests.md](../guides/campaign-quests.md)); они выделяют пассивки, действующие **только пока активен этот набор оружия**. «Weapon Master» у Witchhunter Наёмника конвертирует 100 очков пассивок в очки наборов оружия.
- **Сокеты самоцветов** расположены на древе (часть — в амулетах); в 1.0 сокеты переносятся внутрь кластеров (~18 сокетов на «шоссе» → ~60, некоторые связывают отдельные кластеры); новая ключевая пассивка **Withering Disintegration**.
- Доступ между ветвями: Pathfinder «Path of the Sorceress»/«Path of the Warrior» открывают стартовые пассивки других классов; Oracle «Entwined Realities»/«The Unseen Path» выделяют пассивки рядом с ключевыми пассивками с непройденных путей.
