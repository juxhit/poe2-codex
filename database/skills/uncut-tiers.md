# Uncut Gems, Levels & Quality

> Sources: [poe2db — Skill Gems](https://poe2db.tw/us/Skill_Gems), [Fextralife Gemcutting](https://pathofexile2.wiki.fextralife.com/Gemcutting)

## Uncut gem tiers

- **Uncut Skill Gems / Uncut Support Gems** drop in tiered versions gating by character level.
- Tier names: Rough / Ordinary / Refined / Polished / Superior / Perfect / Exceptional / Flawless — roughly level 1/7/14/22/30/38/46/54+ `(unconfirmed exact thresholds)`.
- You choose which skill to learn when using an Uncut gem — nothing is missable; gem-cutting is optional (drops suffice).

## Gem levels & quality

- Gem levels run **1–20**.
- **Gemcutter's Prism**: +5% quality (quality improves damage/defence stats of the gem).
- **Thaumaturgic Flux L5–20**: levels Kalguuran skill gems directly.
- Vaal Orb outcomes on gems: nothing / +1−1 level / +1−1 support socket / −7 to +3% quality — see [crafting/corruption.md](../crafting/corruption.md).

## Support sockets

| Orb | Result |
|---|---|
| Lesser Jeweller's Orb | 3 support sockets |
| Greater Jeweller's Orb | 4 support sockets |
| Perfect Jeweller's Orb | 5 support sockets |

- Supports socket directly into the skill gem (no links between separate gems).
- Weapon-swap: skills can be locked to weapon set 1 or 2 ([mechanics/movement-controls.md](../mechanics/movement-controls.md)).
