# Support Gems (0.5.x)

> Source: [poe2db — Support Gems](https://poe2db.tw/us Support_Gems) (558 rows; ~530 distinct after dedupe; bracketed number = **tier 1–5**). Rules: [mechanics/index.md](../mechanics/index.md) · Socket counts via Jeweller's Orbs: [uncut-tiers.md](uncut-tiers.md)

## System rules

- Supports socket **directly into skill gems** (and into Meta gems where noted); each support states allowed tags and Support Requirements (+5 Str/Dex/Int per socket).
- **No-duplicate rule:** at EA launch each support could only be linked to **one skill per character**; this restriction was subsequently removed (Fextralife — supports may now socket into multiple skills) `(unconfirmed exact patch)`.
- **Seals standardized (0.5.0):** Unleash, Expand, Salvo, Freezing Salvo share the same Seal rules; Salvo = 1 Seal/s, max 6, 1 projectile per Seal.
- **0.5.0 removals (no longer obtainable):** Infernal Legion III, Shock Conduction II, Overextend.
- **0.5.0 additions:** Minion Splash I & II (Minion-creating Strikes gain Melee Splash), 23 new Lineage supports, 7 Kalguuran supports (Concussive Runes, Fist of Kalguur, Healing Runes, Runeforged Blades, Runic Extraction, Runic Infusion, Scouring Flame — effects `(unconfirmed)`), Rage I–III support Minion skills.
