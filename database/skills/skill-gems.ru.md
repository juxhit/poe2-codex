# Активные камни умений (0.5.x)

> Источники: [poe2db — Skill Gems](https://poe2db.tw/us/Skill_Gems) (419 записей), официальные заметки 0.5.0. Эффекты сжаты до одной строки; числовые диапазоны опущены. Цвета камней: красный = Сила, зелёный = Ловкость, синий = Интеллект. **В 0.5.x нет отдельных секций камней для Sword/Dagger/Flail/Wand/Staff/Sceptre/Talisman** — чары = пул Elemental; Sceptre (оружие на Духе) использует те же камни чар/приспешников; у Flail только `Flail Strike` + общие камни поддержки ближнего боя. Swords/Daggers появятся с 1.0.
