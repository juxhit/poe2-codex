# Неогранённые камни (Uncut Gems), уровни и качество

> Источники: [poe2db — Skill Gems](https://poe2db.tw/us/Skill_Gems), [Fextralife Gemcutting](https://pathofexile2.wiki.fextralife.com/Gemcutting)

## Ступени неогранённых камней

- **Uncut Skill Gems / Uncut Support Gems** выпадают в версиях по ступеням, привязанных к уровню персонажа.
- Названия ступеней: Rough / Ordinary / Refined / Polished / Superior / Perfect / Exceptional / Flawless — примерно уровни 1/7/14/22/30/38/46/54+ `(не подтверждено — точные пороги)`.
- При использовании неогранённого камня вы сами выбираете, какое умение выучить — ничего нельзя пропустить; огранка необязательна (хватит дропа).

## Уровни и качество камней

- Уровни камней: **1–20**.
- **Gemcutter's Prism**: +5% качества (качество улучшает урон/защитные показатели камня).
- **Thaumaturgic Flux L5–20**: напрямую повышает уровни камней умений Kalguuran.
- Результаты Vaal Orb на камнях: ничего / +1−1 уровень / +1−1 слот поддержки / от −7 до +3% качества — см. [crafting/corruption.md](../crafting/corruption.md).

## Слоты поддержки

| Сфера | Результат |
|---|---|
| Lesser Jeweller's Orb | 3 слота поддержки |
| Greater Jeweller's Orb | 4 слота поддержки |
| Perfect Jeweller's Orb | 5 слотов поддержки |

- Камни поддержки вставляются прямо в камень умений (связей между отдельными камнями нет).
- Смена оружия: умения можно привязать к набору оружия 1 или 2 ([mechanics/movement-controls.md](../mechanics/movement-controls.md)).
