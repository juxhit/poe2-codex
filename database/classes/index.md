# Classes

**Path of Exile 2** targets **12 classes / 36 ascendancies**. Status as of 2026-11-17 (patch 0.5.x): **8 playable**, Duelist + Shadow ship with 1.0 (Dec 11, 2026), Marauder + Templar follow post-1.0.

Every class can use any skill gem — identity comes from attributes, starting tree position, weapons, and ascendancies.
