# Warrior

- **Attributes:** Strength (pure)
- **Starting stats:** Str 15 / Dex 7 / Int 7
- **Weapons:** Two-handed Maces; one-handed Mace + Shield
- **Sources:** [Fextralife — Warrior](https://pathofexile2.wiki.fextralife.com/Warrior) · [Maxroll class overview](https://maxroll.gg/poe2/resources/poe-2-class-overview)

## Playstyle

Classic tanky melee brawler that pounds the ground with heavy, slow slams and shrugs off small hits with a large armour and life pool. Uses stuns, knockback and warcries for crowd control while brawling toe-to-toe. The most durable front-line fighter, though slow and demanding for beginners.

## Class mechanic

Active block with a **stagger/stun meter** — holding the blocking stance builds a gauge that leaves him vulnerable if mismanaged. Heavy **stun build-up** on enemies is a core damage/support theme.

## Skill kit

Slam skills (Volcanic Fissure, Seismic Cry-doubled slams), Warcries, totems (Shockwave Totem, Ancestral Warrior Totem). New for 1.0: **Molten Forge**.
