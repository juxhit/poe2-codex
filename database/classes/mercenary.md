# Mercenary

- **Attributes:** Strength/Dexterity (hybrid)
- **Starting stats:** Str 11 / Dex 11 / Int 7
- **Weapons:** Crossbows + grenades
- **Sources:** [Fextralife — Mercenary](https://pathofexile2.wiki.fextralife.com/Mercenary) · [Maxroll class overview](https://maxroll.gg/poe2/resources/poe-2-class-overview)

## Playstyle

An FPS-inspired tactician — pulls the trigger and the bolt fires instantly (no bow draw time), swapping between crossbow archetypes and ammunition mid-fight. Builds revolve around prepping the battlefield with freezes, gas clouds and oil, then detonating combos. WASD movement was added to the game partly for this class.

## Class mechanic

The **crossbow ammunition system** — a reloaded magazine of swappable ammo types (incendiary, permafrost, armor-piercing, etc.) that adapts damage type per engagement; grenade secondary slots.

## Skill kit

Burst-fire, Rapid-fire, Power/Sniper crossbow archetypes; Gas Grenade, Explosive Grenade; utility bolts (Glacial Bolt, Armor Piercing Rounds); combo setups (Gas Grenade + Explosive Shot, Glacial Bolt + Fragmentation Rounds); Artillery Ballistas.
