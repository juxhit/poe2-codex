# Regex для поисковых полей

> Источники: [Mobalytics regex guide](https://mobalytics.gg/poe-2/guides/regex), [Reddit waystone regex](https://www.reddit.com/r/PathOfExile2/comments/1nnh105/some_useful_regular_expressions_for_waystone), [генератор poe2.re](https://poe2.re/waystone)

## Где работает regex

Инвентари торговцев · вкладки сундука · дерево пассивок (Ctrl+F) · дерево Атласа · шкафчики убежища · **окна перекатов путевых камней/планшетов/реликвий** (держите поиск активным).

## Синтаксис

- Оборачивать в `" "`; **`|`** = ИЛИ; **`!`** отдельным закавыченным термином = НЕ (`"!quiver"`).
- Несколько закавыченных терминов объединяются через И. Частичные слова совпадают (`sbo` находит Crossbow).
- Замечен лимит ~50 символов `(не подтверждено, актуально ли сейчас)`.

## Готовые строки

**Торговец для левелинга (арбалеты, скорость передвижения, атаковые моды):**
```
"sbo|ent sp|to att"
```
с исключением колчана:
```
"!quiver" "sbo|ent sp|to att"
```

**Имплиты путевых камней:**
```
"m.+e:"     строка Magic Monsters
"ma.+s:"    строка Rare Monsters
"r.+s:"     строка Item Rarity
```
Rarity ≥10%:
```
"m rar.*([1-9].|\d..)%"
```

**Отфильтровать плохие путевые камни:** используйте генератор — [poe2.re/waystone](https://poe2.re/waystone) (совет: задайте мин/макс **revives в 0**, чтобы найти камни с 6+ модификаторами — имплиты зарядов возрождения съедают слоты имплитов).
