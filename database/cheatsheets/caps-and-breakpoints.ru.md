# Капы и пороги (Breakpoints)

| Бонус крит-урона | база +100% (крит = 200%) |
| Порог оглушения (игрок) | половина макс. жизни (аналог Ailment Threshold) |
| Freeze / Electrocute | 100% накопления → лок 4 с / 5 с |
| Heavy Stun (враги) | 100% шкалы → лок; Phys/Melee наносит +50% накопления |
