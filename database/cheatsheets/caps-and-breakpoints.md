# Caps & Breakpoints

> Full mechanics: [mechanics/defences.md](../mechanics/defences.md), [mechanics/ailments.md](../mechanics/ailments.md)

| Stat | Cap / breakpoint |
|---|---|
| Elemental resistances | **75%** default; max res raises cap to **90%** |
| Chaos resistance | 75% (CI = immune) |
| Armour mitigation | **90%** hard cap; 12000 armour = 50% vs 100-hit |
| Block chance | 75% default; **90%** hard cap |
| Evasion | **95%** hard cap (entropy system) |
| Deflection | **95%** cap (0.5.0 rework) |
| Crit chance | 100% |
| Crit damage bonus | base +100% (crit = 200%) |
| Stun threshold (player) | half of max Life (Ailment Threshold analog) |
| Freeze / Electrocute | 100% build-up → 4s / 5s lock |
| Heavy Stun (enemies) | 100% bar → lockout; Phys/Melee deal +50% buildup |
| Charges (Power/Frenzy/Endurance) | default max 3 each, 15s duration |
| Spirit | no cap; +100 from campaign quests |
| Flask charges | 60–75 typical, ~10/use; 5 slots |
| Charms | up to 3 equipped, 80 charge cap |
| Waystone tiers | 1–16 (T1 = lvl 65 → T16 = 80) |
| Campaign permanent bonuses | +100 Spirit, +30% ele res, 24-26 passive + 25 weapon-set points — [guides/campaign-quests.md](../guides/campaign-quests.md) |
| Ascendancy points | 8 total (trials) |
| Waystone respawns | 6 portals per map (shared in party) |
| Support sockets per gem | 5 max (Perfect Jeweller's Orb) |
| Gem levels | 1–20 |
| Quality | 20% normal, 30% via Vaal Infuser |
| Augment sockets | 2 (body/2H), 1 (1H/helm/gloves/boots) |
| Item explicit mods | 6 max (3 prefix + 3 suffix) |
| Party size | 6 players |
| Map XP death penalty | 10% of current level from ~lvl 65 |
