# Movement & Controls

> Sources: [Mobalytics dodge roll](https://mobalytics.gg/poe-2/guides/dodge-roll-mechanic), [myrtana wiki](https://www.myrtana.net/en/path-of-exile-2/wiki/mechaniky/dodge-roll), [Mobalytics dual spec](https://mobalytics.gg/poe-2/guides/dual-specialisation)

## Dodge roll

- Avoids **Strikes and Projectiles only**; **does not avoid AoE**.
- Maxroll: i-frames cover roughly **80% of the animation**; other sources argue there are **no true invulnerability frames** — the roll makes most strikes/projectiles miss and grants stun resistance `(unconfirmed)` which framing is exact.
- Roll passes through enemies.
- Spirit Walker's Primal Bounty: dodging spends Owl Feathers for Empowerment.

## Sprint

- **Holding the dodge-roll button triggers a Sprint** after the roll — greatly boosts movement speed until stopped; intended for disengaging, not in-combat weaving.
- Pathfinder: Running Assault (no Heavy Stun while sprinting), Relentless Pursuit (immune to Slows).

## WASD

- Supported alongside click-to-move (added partly for the Mercenary). Cursor-tracking after rolls can conflict with aim (community requests to split dodge/sprint binds).

## Weapon set swap

- Default keybind **X**; a weapon can be assigned to both sets.
- Since **0.3, pressing a skill bound to the inactive set auto-swaps** weapons.
- Weapon-set passives apply only while using that set; skills can be locked to set 1 or 2 via "Manage Sockets → Skill Options".
- Witchhunter's Weapon Master: 100 passive points become Weapon Set Skill Points.
- Martial Artist: Martial Master builds Combo regardless of weapon set.
