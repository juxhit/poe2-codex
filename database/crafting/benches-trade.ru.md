# Верстаки, рецепты и трейд

> Источники: [poewiki vendor recipe system](https://www.poewiki.net/wiki/Vendor_recipe_system) (справка PoE1), [Reddit 3-to-1 list](https://www.reddit.com/r/PathOfExile2/comments/1hjtjfg/), [Game8 reforging bench](https://game8.co/games/Path-of-Exile-2/archives/490017), [Mobalytics currency exchange](https://mobalytics.gg/poe-2/guides/currency-exchange), [GGG async trade FAQ](https://www.pathofexile.com/forum/view-thread/3828185)

## Верстак утилизации

- Экипировка → **Artificer's Shards** / валюта качества; экипировка с сокетами → Artificer's Shards; Уникальные предметы имеют особые исходы утилизации.

## Верстак перековки

- **3 предмета одного базового типа → 1 новый предмет** с переброшенными модами (ilvl результата = минимальный ilvl входных).
- Также 3→1 для рун (апгрейд тиров), катализаторов, флаконов/чарм.
- 3 **waystone** одного тира → 1 тиром выше — см. [mechanics/atlas-waystones.md](../mechanics/atlas-waystones.md).
- После 1.0: фрактурированные/Forgemarked-моды взаимодействуют с перековкой ([fractured-desecration.md](fractured-desecration.md)).

## Рецепты торговцев

- В PoE2 **нет классического набора рецептов торговцев из PoE1** — нет подтверждённого рецепта «полный редкий сет» на Chaos Orb (не подтверждено, есть ли скрытые награды за полные сеты).
- Рецептоподобный функционал переехал в Верстак утилизации/Верстак перековки выше.

## Торговые системы

- **Faustus (Currency Exchange):** мгновенные обмены валюты по рыночному курсу; ордера покупки/продажи стоят **золота** (растёт со стоимостью).
- NPC: Finn (Акт 1, Clearfell), Risu (Акт 2), Alva (Акт 3 + убежище); Ange (обмен/маркет эпохи 0.5.5).
- **Ange / Merchant Tabs (0.3.0):** асинхронная торговля предметами — выставляйте экипировку в Merchant Tabs убежища по своей цене; **комиссию в золоте платит покупатель, продавец не платит ничего**.
- Предмет за предмет: [pathofexile.com/trade2](https://www.pathofexile.com/trade2) + шёпот/подбор в один клик.
