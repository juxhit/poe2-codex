# Фрактура (Fractured Items) и Desecration

> Источники: [Mobalytics fracturing orbs](https://mobalytics.gg/poe-2/guides/fracturing-orbs), [poe2db — Desecrated Modifiers](https://poe2db.tw/us/Desecrated_Modifiers), [0.5.0 notes](https://maxroll.gg/poe2/news/0-5-0-patch-notes-return-of-the-ancients), [PoE Vault 1.0 league](https://www.poe-vault.com/poe2/news/conquerors-of-wraeclast-explained-path-of-exile-2s-1-0-league-has-you-raise-an-army)

## Fracturing Orb

- Применим к Редкому с **4+ явными модификаторами**; навсегда фрактурирует («закрепляет») один **случайный** мод.
- Фрактурированные моды никогда нельзя изменить.
- Частая стратегия: спамить Chaos до нужной раскладки модов, затем фрактурировать.
- 0.5.0: для использования требует узел специализации Атласа.

## Desecration Бездны (эксклюзивные моды, не фрактура)

- **Abyssal Bones** проводят Desecration предмета, добавляя *нераскрытый модификатор Desecrated* (если модов 6, удаляется случайный).
- Раскрывается через **Well of Souls** / Gnawed Bones; моды Desecrated — эксклюзивные аффиксы, управляемые оменами Бездны — см. [omens.md](omens.md).

## Перековка «Forgemarked» в 1.0 (Conquerors of Wraeclast)

- Материалы только из Treasury — **Crimson Iron** выбирает модификатор, который станет *Forgemarked*.
- Последующая перековка предмета заменяет этот модификатор случайным новым, который становится **навсегда Фрактурированным**.
- Склянки **Infused Blood** добавляют вместо случайных конкретные новые модификаторы (например, умения хаоса накладывают «Engulfed in Darkness» при ударе; удары из стелса накладывают «Corrupted Blood» — показано для Shadow).
- Подробности: [1-0-crafting.md](1-0-crafting.md)
