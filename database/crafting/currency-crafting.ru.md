# Крафт валютой

> Источники: [Mobalytics currency guide](https://mobalytics.gg/poe-2/guides/currency-guide), [Maxroll how-to-craft](https://maxroll.gg/poe2/resources/how-to-craft-in-path-of-exile-2), [Maxroll 0.5.0 notes](https://maxroll.gg/poe2/news/0-5-0-patch-notes-return-of-the-ancients)

## Слоты модификаторов по редкости

| Редкость | Явные моды |
|---|---|
| Обычный | 0 |
| Магический | макс. 2 (1 префикс + 1 суффикс) |
| Редкий | макс. 6 (3 префикса + 3 суффикса) |
| Уникальный | не может изменяться обычными орбами крафта |

## Основные орбы

| Валюта | Эффект |
|---|---|
| Orb of Transmutation | Обычный → Магический с 1 модификатором. 10 Transmutation Shards (распыление Магических предметов) = 1 орб. |
| Orb of Augmentation | Добавляет случайный модификатор Магическому предмету. |
| Orb of Alchemy | Обычный → Редкий с 4 модификаторами. Реже, чем в PoE1. |
| Regal Orb | Магический → Редкий, добавляет 1 модификатор. 10 Regal Shards (распыление Редких) = 1 орб. |
| Exalted Orb | Добавляет случайный модификатор Редкому (до 6 всего). |
| Chaos Orb | Удаляет один случайный модификатор, добавляет новый случайный (Редкий). |
| Orb of Annulment | Удаляет один случайный модификатор. |
| Divine Orb | Перебрасывает числовые значения в диапазоне тира модификатора. Дорогая торговая валюта. |
| Orb of Chance | Обычный предмет → случайный Уникальный этой базы, либо уничтожает его. 10 Chance Shards (распыление Уникальных) = 1 орб. |
| Vaal Orb | Непредсказуемо коррупит предмет — см. [corruption.md](corruption.md). |
| Mirror of Kalandra | Дублирует не-Уникальный предмет. Самая редкая валюта в игре. |
| Greater / Perfect orbs | Более высокие тиры Transmutation/Augmentation/Exalted и т.д. — гарантируют минимальные тиры модов; в 0.5.0 сделаны реже; Greater Transmutation/Augmentation — мин. уровень мода 44 (было 55), дроп в Акте 4. |
| Fracturing Orb | Навсегда закрепляет один случайный явный мод на Редком с 4+ модами — см. [fractured-desecration.md](fractured-desecration.md). |
| Hinekora's Lock | Предпросматривает точный исход следующей применённой валюты (детерминированный крафт). |

## Сокеты камней поддержки (замена линков в PoE2)

| Валюта | Эффект |
|---|---|
| Lesser Jeweller's Orb | Гарантирует камню умения 2 сокета поддержки (гарантированный дроп в Акте 3) |
| Greater Jeweller's Orb | Камень с 3 сокетами поддержки |
| Perfect Jeweller's Orb | Камень с 4 сокетами поддержки |

## Изменения редкости/дропа в 0.5.0

- Валюта Greater/Perfect стала реже; Transmutation и Augmentation — значительно реже; **Divine Orb чаще**.
- Исходы Коррупции/"Sanctify" теперь **умножают значения модификаторов**, а не перебрасывают новые случайные.

## Стандартный цикл

1. Белая база → **Transmutation** (Магический, 1 мод) → **Augmentation** (заполнить 2-й слот).
2. Оценить; **Regal** до Редкого (+1 мод).
3. Спам **Exalted** до 6 модов, используя Омены для контроля префиксов/суффиксов — см. [omens.md](omens.md).
4. Чинить ошибки через **Chaos** (заменить мод), **Annulment** (убрать) или начать заново.
5. Финал: **Divine** (переброс чисел), валюта качества, руны/сокеты, затем **Vaal последним**.
- Цикл высоких тиров использует вместо них орбы Greater/Perfect и эссенции — см. [essences.md](essences.md).
