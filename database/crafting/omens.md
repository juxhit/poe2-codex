# Omens

> Sources: [Mobalytics omen crafting](https://mobalytics.gg/poe-2/guides/omen-crafting), [poe2db — Omen](https://poe2db.tw/Omen), [Fextralife Omens](https://pathofexile2.wiki.fextralife.com/Omens)

Consumable "activate next craft" modifiers, bought with Tribute at **Ritual** encounters ([mechanics/league-mechanics.md](../mechanics/league-mechanics.md)); Abyss Omens drop from the Abyss; tradeable via Currency Exchange.

**Naming: Sinistral = affects Prefixes · Dextral = affects Suffixes.**

!!! tip "Deterministic crafting combo"
    Stack omens to control both sides: **Greater Exaltation** (+2 mods) with **Dextral/Sinistral Exaltation** picks the side, **Whittling** makes Chaos Orbs remove the *lowest-level* mod, and **Catalysing Exaltation** spends Catalyst Quality to bias tag-matching exalts.

## Core omens

| Omen | Effect |
|---|---|
| Dextral / Sinistral Exaltation | Next Exalted Orb adds only Suffixes / only Prefixes |
| Greater Exaltation | Next Exalted Orb adds **two** modifiers |
| Dextral / Sinistral Annulment | Next Orb of Annulment removes only Suffix / only Prefix |
| Dextral / Sinistral Erasure | Next Chaos Orb removes only Suffix / only Prefix |
| Dextral / Sinistral Crystallisation | Next Perfect/Corrupted Essence removes only Suffix / Prefix |
| Homogenising Exaltation | Exalted Orb adds a mod sharing tags with existing mods |
| Homogenising Coronation | Same, for Regal Orb |
| Whittling | Chaos Orb removes the lowest-level modifier |
| Catalysing Exaltation | Exalted Orb consumes Catalyst Quality to raise odds of a matching-tag mod |
| Corruption | Next Vaal Orb always produces an outcome (removes "no change") |
| the Ancients | Next Orb of Chance upgrades to a random Unique of the same Item Class |
| Chance | Next Orb of Chance can't destroy the item; guarantees Unique of the exact base |
| Sanctification | Next Divine Orb "Sanctifies": rerolls each mod 80–120%, item can't be crafted further |
| the Blessed | Next Divine Orb rerolls only Implicit modifiers |

## Abyss omens (Desecration)

| Omen | Effect |
|---|---|
| Dextral / Sinistral Necromancy | Next Desecration adds only Suffixes / Prefixes |
| Light | Next Orb of Annulment removes only Desecrated modifiers |
| Abyssal Echoes | Next Desecrated mod reveal can be rerolled once |
| Putrefaction | Next Desecration replaces all mods (up to 6 Desecrated) and Corrupts the item |
| the Blackblooded / the Liege / the Sovereign | Guarantee a Kurgal / Amanamu / Ulaman modifier on next Desecration |

## 0.5.0 changes

- **Removed:** Omen of Corruption, Omen of Recombination.
- **Added:** Omen of Chaotic Effectiveness (next Chaos Orb replaces all Waystone modifiers with ones not granting Monster Effectiveness; up to 3 stack).
- Chaotic Rarity/Quantity/Monsters omens inverted — they now *prevent* modifiers of their type.
