# Тиры модификаторов и шпаргалка по ilvl

> Что задокументировано, а что (нет данных) — полные таблицы тиров в [poe2db modifier index](https://poe2db.tw/us/Modifiers). Шаблон: [../meta/templates/mechanic.md](../meta/templates/mechanic.md)

## Структура

- Редкие: макс. **6 явных модов — 3 префикса + 3 суффикса**; Магические: 1+1; Обычные: 0 — см. [currency-crafting.md](currency-crafting.md).
- Каждая база несёт **имплицит**; базы Runemastered (65 ур.) получают несколько имплицитов — см. [items/rarity.md](../items/rarity.md).
- Slot-shifters (кольца/амулеты Dusk/Gloam/Penumbra/Tenebrous) меняют баланс допустимых префиксов и суффиксов.

## Ограничения по ilvl (известные)

| Ограничение | Требование |
|---|---|
| Greater-валюта на цель | моды предмета мин. уровня **35** |
| Perfect-валюта на цель | моды предмета мин. уровня **50** |
| Greater Transmutation/Augmentation | добавляют моды мин. уровня **44** (было 55), дроп в Акте 4 |
| Бесплатное наложение Runic Ward | броня с **ilvl < 55** (выше — обмен базовых защит) |
| Veridical Chain / базы Runemastered | 65 ур. |
| Fracturing Orb | Редкий с **4+ явными модами** |
| Exalted Orb | только Редкие |

## Система тиров (правила)

- Более высокий ilvl открывает более высокие тиры модификаторов (числовые диапазоны расширяются с каждым тиром).
- **Divine Orb** перебрасывает значения в пределах диапазона текущего тира — тир он повысить не может.
- **Hinekora's Lock** предпросматривает исход следующей валюты (детерминированная проверка перед применением).
- Эссенции/сплавы принудительно дают гарантированные моды, масштабируемые тиром эссенции (Lesser→Perfect) — см. [essences.md](essences.md), [runeforging.md](runeforging.md).
