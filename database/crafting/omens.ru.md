# Омены

> Источники: [Mobalytics omen crafting](https://mobalytics.gg/poe-2/guides/omen-crafting), [poe2db — Omen](https://poe2db.tw/Omen), [Fextralife Omens](https://pathofexile2.wiki.fextralife.com/Omens)

Расходники «активировать следующий крафт», покупаются за Tribute на встречах **Ритуала** ([mechanics/league-mechanics.md](../mechanics/league-mechanics.md)); Омены Бездны дропают из Бездны; торгуются через Currency Exchange.

**Именование: Sinistral = влияет на префиксы · Dextral = влияет на суффиксы.**

## Основные омены

| Омен | Эффект |
|---|---|
| Dextral / Sinistral Exaltation | Следующий Exalted Orb добавляет только суффиксы / только префиксы |
| Greater Exaltation | Следующий Exalted Orb добавляет **два** модификатора |
| Dextral / Sinistral Annulment | Следующий Orb of Annulment удаляет только суффикс / только префикс |
| Dextral / Sinistral Erasure | Следующий Chaos Orb удаляет только суффикс / только префикс |
| Dextral / Sinistral Crystallisation | Следующая Perfect/Corrupted эссенция удаляет только суффикс / префикс |
| Homogenising Exaltation | Exalted Orb добавляет мод, чьи теги совпадают с уже имеющимися модами |
| Homogenising Coronation | То же, для Regal Orb |
| Whittling | Chaos Orb удаляет модификатор самого низкого уровня |
| Catalysing Exaltation | Exalted Orb поглощает качество Катализатора, повышая шансы мода с совпадающим тегом |
| Corruption | Следующий Vaal Orb всегда даёт какой-то исход (убирает «без изменений») |
| the Ancients | Следующий Orb of Chance даёт случайного Уникального того же класса предметов |
| Chance | Следующий Orb of Chance не может уничтожить предмет; гарантирует Уникального точно этой базы |
| Sanctification | Следующий Divine Orb «Sanctify»: перебрасывает каждый мод на 80–120%, предмет больше нельзя крафтить |
| the Blessed | Следующий Divine Orb перебрасывает только имплицитные модификаторы |

## Омены Бездны (Desecration)

| Омен | Эффект |
|---|---|
| Dextral / Sinistral Necromancy | Следующая Desecration добавляет только суффиксы / префиксы |
| Light | Следующий Orb of Annulment удаляет только моды Desecrated |
| Abyssal Echoes | Следующее раскрытие мода Desecrated можно перебросить один раз |
| Putrefaction | Следующая Desecration заменяет все моды (до 6 Desecrated) и коррупит предмет |
| the Blackblooded / the Liege / the Sovereign | Гарантируют мод Kurgal / Amanamu / Ulaman при следующей Desecration |

## Изменения 0.5.0

- **Удалены:** Omen of Corruption, Omen of Recombination.
- **Добавлены:** Omen of Chaotic Effectiveness (следующий Chaos Orb заменяет все моды Waystone на моды, не дающие Monster Effectiveness; стакается до 3).
- Омены Chaotic Rarity/Quantity/Monsters инвертированы — теперь они *предотвращают* модификаторы своего типа.
